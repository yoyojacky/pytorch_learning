## 核心概念讲解

### 什么是超参数

训练神经网络时有两类"参数"：

- **模型参数**：权重 W 和偏置 b，它们由优化器通过反向传播**自动学习**，我们只管初始值，不直接设定最终值。
- **超参数**：学习率、批量大小、训练轮数、网络层数等，它们**无法通过梯度下降学到**，只能由人（或调参算法）在训练前设定。

超参数选得好不好，直接决定模型训练的成败。本章用三组实验对比三种最重要的调参手段。

### 批量大小（batch size）

batch（批次）指每次参数更新所用到的样本数量。800 个样本、batch_size=8，意味着每轮（epoch，即完整过一遍数据集）要更新 100 次参数；batch_size=256 则只更新约 4 次（800/256 = 3.125，向上取整为 4 个批次，最后一批只有 32 个样本）。

一般规律：

- **小批量**：每次更新只看少量样本，梯度噪声大，训练曲线抖动明显，但噪声有时能帮助模型跳出差的局部最优，泛化往往更好；同时更新次数多，同样轮数下"学得更多"。
- **大批量**：梯度估计准确、曲线平稳，但更新次数少，同样轮数下学得少，且容易收敛到"平坦但泛化差"的解。

### 学习率衰减（learning rate decay）

学习率（learning rate，lr）控制每次参数更新的步长：

```
参数新值 = 参数旧值 - lr × 梯度
```

- lr 太大：步子太大，在最优点附近来回震荡甚至发散；
- lr 太小：收敛慢，可能还没走到最优点训练就结束了。

**学习率衰减**的思想是"前期大步探索、后期小步精调"：开始时用较大的 lr 快速接近最优点，之后按规则把 lr 调小，避免在最优点附近震荡。本章使用的 `StepLR` 是最简单的衰减策略：**每过固定轮数，把学习率乘以一个固定系数**（例如每 5 轮乘以 0.5，即衰减一半）。

### 网格搜索与贝叶斯优化

- **网格搜索（Grid Search）**：给每个超参数列几个候选值，然后像表格的格子一样**穷举所有组合**，逐个训练评估，选效果最好的组合。优点是简单可靠；缺点是组合数随候选值个数爆炸式增长（2 个批量 × 3 个学习率 = 6 次训练，再加一个超参数就翻倍）。
- **贝叶斯优化（Bayesian Optimization）**：不盲目穷举，而是根据已经试过的结果，建立一个"哪片区域更可能出好结果"的概率模型，优先去最有希望的区域试下一组。Optuna 是常用的自动调参库，基本用法是 `pip install optuna` 后定义一个 objective 函数（输入一组超参数、返回评估分数），剩下的搜索交给库完成。

## 完整代码

```python
"""
第 6 章：超参数调优 —— 学习率衰减、批量大小、网格搜索
对应赛项知识点：知道学习率衰减、批量大小选择对训练稳定性的影响；
理解网格搜索、贝叶斯优化等调参方法的原理（Optuna 的思想演示）
"""
import torch  # 导入 PyTorch
import torch.nn as nn  # 神经网络模块
from torch.utils.data import DataLoader, TensorDataset  # 数据集封装与加载

torch.manual_seed(42)  # 固定随机种子

# ========== 1. 准备数据 ==========
n = 800  # 800 个样本
X = torch.randn(n, 6)  # 6 个特征
y = ((X[:, 0] + X[:, 1] * X[:, 2] - X[:, 3]) > 0).long()  # 非线性规则生成标签

dataset = TensorDataset(X, y)  # 打包数据集

# ========== 2. 一个可复用的训练函数（调参实验的基础） ==========
def train_one_run(batch_size, lr, epochs=15, use_scheduler=False):
    """用指定的超参数训练一次，返回最终训练准确率"""
    loader = DataLoader(dataset, batch_size=batch_size, shuffle=True)  # 按给定批量构建加载器
    model = nn.Sequential(  # 简单 MLP：6 -> 32 -> 2
        nn.Linear(6, 32),  # 全连接层
        nn.ReLU(),  # 激活
        nn.Linear(32, 2),  # 输出层
    )
    optimizer = torch.optim.SGD(model.parameters(), lr=lr)  # SGD，学习率为参数 lr
    scheduler = torch.optim.lr_scheduler.StepLR(optimizer, step_size=5, gamma=0.5)
    # StepLR：每过 step_size=5 轮，学习率乘以 gamma=0.5（即衰减一半）—— 赛项考点：学习率衰减

    for epoch in range(epochs):  # 训练指定轮数
        for bx, by in loader:  # 逐批次训练
            loss = nn.CrossEntropyLoss()(model(bx), by)  # 前向 + 交叉熵损失
            optimizer.zero_grad()  # 清梯度
            loss.backward()  # 反向传播
            optimizer.step()  # 更新参数
        if use_scheduler:  # 如果启用学习率衰减
            scheduler.step()  # 每轮结束后让调度器更新学习率
    with torch.no_grad():  # 评估关闭梯度
        acc = (model(X).argmax(dim=1) == y).float().mean().item()  # 计算整体准确率
    return acc  # 返回准确率

# ========== 3. 实验一：对比不同批量大小（batch size） ==========
print("=== 实验一：批量大小对训练的影响 ===")
for bs in [8, 64, 256]:  # 分别尝试小、中、大三种批量
    acc = train_one_run(batch_size=bs, lr=0.1)  # 训练一次
    print(f"batch_size={bs:4d} -> 准确率 {acc:.2%}")  # 小批量噪声大但泛化好，大批量稳定但可能陷入平坦解

# ========== 4. 实验二：学习率衰减 vs 不衰减 ==========
print("\n=== 实验二：学习率衰减的作用 ===")
acc_fixed = train_one_run(batch_size=32, lr=0.5, use_scheduler=False)  # 固定大学习率
acc_decay = train_one_run(batch_size=32, lr=0.5, use_scheduler=True)  # 同样的学习率但逐步衰减
print(f"固定学习率 0.5     -> 准确率 {acc_fixed:.2%}")
print(f"学习率 0.5 + 衰减  -> 准确率 {acc_decay:.2%}")  # 衰减通常更好：前期大步探索，后期小步精调

# ========== 5. 实验三：网格搜索（Grid Search） ==========
print("\n=== 实验三：网格搜索找最优超参数 ===")
results = {}  # 字典保存每组超参数的结果
for bs in [16, 64]:  # 遍历批量候选值
    for lr in [0.01, 0.1, 0.5]:  # 遍历学习率候选值 —— 两层循环穷举所有组合，这就是网格搜索
        acc = train_one_run(batch_size=bs, lr=lr, use_scheduler=True)  # 训练并评估
        results[(bs, lr)] = acc  # 记录结果
        print(f"bs={bs:3d}, lr={lr:.2f} -> {acc:.2%}")

best = max(results, key=results.get)  # 找准确率最高的超参数组合
print(f"\n最优组合: batch_size={best[0]}, lr={best[1]}, 准确率={results[best]:.2%}")
# 提示：贝叶斯优化（如 Optuna）与网格搜索目标相同，但会根据历史结果"聪明地"选择下一组
# 尝试的超参数，用更少的试验找到更优组合。用法：pip install optuna 后定义 objective 函数即可。
```

### 第 1 部分：准备数据

```python
n = 800  # 800 个样本
X = torch.randn(n, 6)  # 6 个特征
```

- `n = 800` —— 设定样本数量为 800，存进变量 `n`，后面生成数据时引用它，想改样本量只需改这一处。
- `X = torch.randn(n, 6)` —— 生成形状为 `(800, 6)` 的特征张量，每个元素服从标准正态分布（均值 0、方差 1）。可以理解为 800 条数据，每条有 6 个特征（比如 6 项检测指标）。

```python
y = ((X[:, 0] + X[:, 1] * X[:, 2] - X[:, 3]) > 0).long()  # 非线性规则生成标签
```

- `X[:, 0]` —— 取所有样本的第 0 个特征，形状 `(800,)`。`:` 表示"这一维全要"。
- `X[:, 1] * X[:, 2]` —— 第 1 个特征和第 2 个特征**逐元素相乘**，形状仍为 `(800,)`。这是一个交叉项，让标签规则具有**非线性**——特征的乘积无法被一条直线（线性模型）表达，所以我们需要带隐藏层的 MLP 才能学好它。
- `X[:, 0] + X[:, 1] * X[:, 2] - X[:, 3]` —— 按运算优先级先算乘法再做加减，得到一个 `(800,)` 的分数。注意这里体现了广播之外的要点：形状相同的张量做逐元素运算，形状不变。
- `(...) > 0` —— 逐元素比较，大于 0 为 `True`、否则为 `False`，得到 `(800,)` 的布尔张量。这一步把连续分数变成"是/否"两类。
- `.long()` —— 把布尔张量转成 64 位整型（`True→1, False→0`）。**这是必须的一步**：`nn.CrossEntropyLoss` 要求标签是 `long` 类型的类别编号，直接传布尔张量会报错。
- 整行的效果：用一条非线性规则给 800 个样本打上 0/1 标签，形状 `(800,)`。

```python
dataset = TensorDataset(X, y)  # 打包数据集
```

- `TensorDataset(X, y)` —— 把特征 `X` 和标签 `y` 按第一个维度对齐打包：取 `dataset[i]` 就得到 `(X[i], y[i])` 这一对。它是 `DataLoader` 的"原料"，DataLoader 只接受数据集对象，不能直接传两个张量。

### 第 2 部分：可复用的训练函数

这是本章的"发动机"——把一次完整的训练封装成函数，超参数通过参数传入，后面三组实验只是反复调用它。

```python
def train_one_run(batch_size, lr, epochs=15, use_scheduler=False):
    """用指定的超参数训练一次，返回最终训练准确率"""
```

- `def train_one_run(batch_size, lr, epochs=15, use_scheduler=False):` —— 定义函数 `train_one_run`（训练一次）。四个参数：
  - `batch_size`：批量大小，必填；
  - `lr`：学习率，必填；
  - `epochs=15`：训练轮数，默认 15。epoch 指完整过一遍数据集；
  - `use_scheduler=False`：是否启用学习率衰减，默认关闭。
  - 把要做实验的超参数设计成函数参数，把不想改的（epochs）给上默认值，是写调参实验的基本功。
- 第二行是函数的 docstring，说明函数的输入（一组超参数）和输出（最终训练准确率）。

```python
    loader = DataLoader(dataset, batch_size=batch_size, shuffle=True)  # 按给定批量构建加载器
```

- `DataLoader(dataset, batch_size=batch_size, shuffle=True)` —— 基于全局的 `dataset` 构建一个数据加载器：
  - `batch_size=batch_size` —— 每批取多少个样本，直接用传进来的超参数。batch_size=8 时共有 100 批，batch_size=256 时只有 4 批（3 整批 + 1 个 32 样本的尾批）。
  - `shuffle=True` —— 每轮开始前打乱样本顺序，避免模型记住样本排列的规律，是训练集的标配（评估时则不需要打乱）。
- 注意 `loader` 在函数内部创建：每次调用 `train_one_run` 都会得到一个全新的加载器，保证各次实验互不干扰。

```python
    model = nn.Sequential(  # 简单 MLP：6 -> 32 -> 2
        nn.Linear(6, 32),  # 全连接层
        nn.ReLU(),  # 激活
        nn.Linear(32, 2),  # 输出层
    )
```

- `nn.Sequential(...)` —— 把若干层按顺序串成一个模型，输入会依次流过每一层。这是一个 MLP（多层感知机），结构为 6 → 32 → 2。
- `nn.Linear(6, 32)` —— 全连接层（线性层）：输入 6 维、输出 32 维，内部包含形状 `(32, 6)` 的权重矩阵和 `(32,)` 的偏置，数学上计算 `y = xWᵀ + b`。输入形状 `(batch, 6)`，输出形状 `(batch, 32)`。
- `nn.ReLU()` —— ReLU 激活函数，逐元素做 `max(0, x)`，负数变 0、正数不变。没有它，两个线性层叠起来等价于一个线性层，就学不会标签里的非线性交叉项。形状不变，仍是 `(batch, 32)`。
- `nn.Linear(32, 2)` —— 输出层：32 维压到 2 维，对应二分类的两个类别得分（logits，未归一化的原始分数）。输出形状 `(batch, 2)`。
- **每次调用函数都会重新创建模型**：权重重新随机初始化，这正是我们要的——每组超参数都从同一起点（种子固定，初始权重相同）开始，对比才公平。

```python
    optimizer = torch.optim.SGD(model.parameters(), lr=lr)  # SGD，学习率为参数 lr
```

- `torch.optim.SGD(...)` —— 创建 SGD（随机梯度下降）优化器。
- `model.parameters()` —— 把模型里所有可学习参数（两个 Linear 层的权重和偏置）交给优化器管理，之后 `optimizer.step()` 更新的就是它们。
- `lr=lr` —— 学习率用传进来的超参数，这样不同实验可以设不同的 lr。

```python
    scheduler = torch.optim.lr_scheduler.StepLR(optimizer, step_size=5, gamma=0.5)
    # StepLR：每过 step_size=5 轮，学习率乘以 gamma=0.5（即衰减一半）—— 赛项考点：学习率衰减
```

- `torch.optim.lr_scheduler.StepLR(...)` —— 创建一个"阶梯式"学习率调度器，它绑定在上面那个优化器上，作用是按轮数自动调整优化器里的 lr。
- `step_size=5` —— 每过 5 个 epoch 调整一次。
- `gamma=0.5` —— 每次调整时把学习率乘以 0.5，即衰减一半。
- 本章 epochs=15，所以若启用衰减，学习率轨迹是：第 0~4 轮 lr=初始值，第 5~9 轮 lr=初始值×0.5，第 10~14 轮 lr=初始值×0.25。
- 注意：调度器只是**创建**出来了，是否真正生效取决于后面的 `if use_scheduler: scheduler.step()`。

### 训练循环

```python
    for epoch in range(epochs):  # 训练指定轮数
        for bx, by in loader:  # 逐批次训练
```

- `for epoch in range(epochs):` —— 外层循环按轮数训练，默认 15 轮。变量 `epoch` 这里没被用到，只是控制次数。
- `for bx, by in loader:` —— 内层循环从加载器逐批取数据：`bx` 是本批特征，形状 `(batch_size, 6)`（最后一批可能更小）；`by` 是本批标签，形状 `(batch_size,)`。遍历完 loader 即过完一遍数据集。

```python
            loss = nn.CrossEntropyLoss()(model(bx), by)  # 前向 + 交叉熵损失
```

- `model(bx)` —— 前向传播：本批数据流过 MLP，输出形状 `(batch_size, 2)` 的 logits。
- `nn.CrossEntropyLoss()` —— 临时创建一个交叉熵损失函数对象。交叉熵衡量"模型给正确类别的概率"有多高，是分类任务的标准损失。
- `nn.CrossEntropyLoss()(model(bx), by)` —— 调用损失函数：第一个参数是模型输出 `(batch_size, 2)`，第二个是真实标签 `(batch_size,)`，返回一个标量（0 维张量）损失值。内部自动做了 softmax + 取负对数似然，所以模型输出**不需要**自己过 softmax——这是常见坑，多加一层 softmax 反而会让训练变差。
- 每次循环都新建一个损失对象其实没必要（提到循环外创建一次即可），但功能上没有问题，本章为了行数紧凑写在一行里。

```python
            optimizer.zero_grad()  # 清梯度
            loss.backward()  # 反向传播
            optimizer.step()  # 更新参数
```

- `optimizer.zero_grad()` —— 把上一轮累积在所有参数上的梯度清零。**PyTorch 默认梯度是累加的**，不清零的话梯度会越滚越大，训练直接乱掉。这是训练循环三件套的第一步。
- `loss.backward()` —— 反向传播：从损失出发，用链式法则算出每个参数对损失的梯度，存到各参数的 `.grad` 属性里。
- `optimizer.step()` —— 优化器读取每个参数的 `.grad`，按 `参数 -= lr × 梯度` 更新一次参数。至此一个批次训练完成。
- 这三行的顺序是固定套路：清零 → 反传 → 更新，顺序错了训练就不对。

```python
        if use_scheduler:  # 如果启用学习率衰减
            scheduler.step()  # 每轮结束后让调度器更新学习率
```

- 注意缩进：`if` 与内层 `for bx, by in loader` 平齐，即**每轮（epoch）结束后**判断一次，而不是每个批次后。
- `if use_scheduler:` —— 只有调用函数时传了 `use_scheduler=True`，衰减才生效。这就是实验二能对比"衰减 vs 不衰减"的开关。
- `scheduler.step()` —— 告诉调度器"一轮结束了"，调度器内部计数加 1，每到第 5、10 轮就把优化器的 lr 乘以 0.5。
- 常见坑：`scheduler.step()` 必须放在 `optimizer.step()` 之后（本章按轮调用，自然满足），旧版 PyTorch 顺序反了会报警告。

### 评估与返回

```python
    with torch.no_grad():  # 评估关闭梯度
        acc = (model(X).argmax(dim=1) == y).float().mean().item()  # 计算整体准确率
    return acc  # 返回准确率
```

- `with torch.no_grad():` —— 进入"不记录梯度"的上下文。评估时只做前向、不做反传，关掉梯度记录可以省内存、提速，也防止误更新。这是一个好习惯：任何不需要梯度的推理代码都该包在里面。
- `model(X)` —— 用全部 800 个样本做一次前向，输出形状 `(800, 2)`。这里直接用 `X` 而不是 loader，因为只是算预测，不需要分批（数据量小）。
- `.argmax(dim=1)` —— 沿第 1 维（类别维）取最大值的**下标**，即模型预测的类别编号，形状变成 `(800,)`。哪个类别得分高就预测哪个。
- `== y` —— 逐元素与真实标签比较，得到 `(800,)` 的布尔张量，`True` 表示这个样本预测正确。
- `.float()` —— 布尔转浮点：`True→1.0, False→0.0`。
- `.mean()` —— 求平均值，1 和 0 的平均值正是"预测正确的比例"，即准确率，结果是一个 0 维张量。
- `.item()` —— 把 0 维张量取出为 Python 普通浮点数，方便后面打印和比较。
- `return acc` —— 返回准确率（0~1 之间的小数）。函数到此结束。
- 注意：这里的准确率是**训练集**上的准确率（评估用的就是训练数据 `X, y`），本章的目的是对比超参数的相对好坏，严格项目中应该用单独的验证集/测试集评估。

```python
print("=== 实验一：批量大小对训练的影响 ===")
```

```python
for bs in [8, 64, 256]:  # 分别尝试小、中、大三种批量
```

### 第 4 部分：实验二 —— 学习率衰减

```python
print("\n=== 实验二：学习率衰减的作用 ===")
```

- `\n` 是换行符，打印前先空一行，把三组实验的输出分隔开。

```python
acc_fixed = train_one_run(batch_size=32, lr=0.5, use_scheduler=False)  # 固定大学习率
```

```python
print(f"固定学习率 0.5     -> 准确率 {acc_fixed:.2%}")
print(f"学习率 0.5 + 衰减  -> 准确率 {acc_decay:.2%}")  # 衰减通常更好：前期大步探索，后期小步精调
```

### 第 5 部分：实验三 —— 网格搜索

```python
print("\n=== 实验三：网格搜索找最优超参数 ===")
results = {}  # 字典保存每组超参数的结果
```

- `results = {}` —— 创建一个空字典，键将是超参数组合 `(bs, lr)`，值是该组合训练出的准确率。

```python
for bs in [16, 64]:  # 遍历批量候选值
    for lr in [0.01, 0.1, 0.5]:  # 遍历学习率候选值 —— 两层循环穷举所有组合，这就是网格搜索
        acc = train_one_run(batch_size=bs, lr=lr, use_scheduler=True)  # 训练并评估
        results[(bs, lr)] = acc  # 记录结果
        print(f"bs={bs:3d}, lr={lr:.2f} -> {acc:.2%}")
```

- `for bs in [16, 64]:` —— 外层循环遍历批量大小的 2 个候选值。
- `for lr in [0.01, 0.1, 0.5]:` —— 内层循环遍历学习率的 3 个候选值。两层循环嵌套后，`(bs, lr)` 的全部 2×3=6 种组合都会被试到——这就是"网格"：把每个超参数看成一根轴，候选值是轴上的刻度，所有组合构成一张网格，逐格试验。
- `acc = train_one_run(batch_size=bs, lr=lr, use_scheduler=True)` —— 用当前组合训练一次，这次统一开启学习率衰减。
- `results[(bs, lr)] = acc` —— 以元组 `(bs, lr)` 为键、准确率为值，存入字典。例如 `results[(16, 0.01)] = 0.8512`。
- `print(f"bs={bs:3d}, lr={lr:.2f} -> {acc:.2%}")` —— 打印当前组合及其准确率。`{bs:3d}` 宽度 3 右对齐；`{lr:.2f}` 保留 2 位小数，让 0.1 显示为 `0.10`，对齐美观。

```python
best = max(results, key=results.get)  # 找准确率最高的超参数组合
```

- `max(results, key=results.get)` —— 在字典的所有键（即所有超参数组合）中，找出"值最大"的那个键：
  - `max` 遍历字典时默认遍历键；
  - `key=results.get` 指定比较依据——对每个键调用 `results.get(键)` 取它的准确率，按准确率比大小；
  - 返回准确率最高的那个键，即元组 `(bs, lr)`。
- 这是 Python 里"按值找键"的经典写法，要理解成"在组合里找准确率最高者"，而不是"找最大的键"。

```python
print(f"\n最优组合: batch_size={best[0]}, lr={best[1]}, 准确率={results[best]:.2%}")
```

- `best[0]`、`best[1]` —— 元组解出最优的 batch_size 和 lr；`results[best]` 取出对应的最高准确率，一并打印。

```python
# 提示：贝叶斯优化（如 Optuna）与网格搜索目标相同，但会根据历史结果"聪明地"选择下一组
# 尝试的超参数，用更少的试验找到更优组合。用法：pip install optuna 后定义 objective 函数即可。
```

- 末尾两行注释是拓展阅读：网格搜索是"无脑穷举"，贝叶斯优化则利用已有试验结果推断下一个最值得尝试的组合，在组合空间很大时能省下大量训练时间。本章只需理解思想，比赛或实际工作中需要时再用 Optuna 落地。


逐项解读：

- **实验一**：批量从 8 增大到 256，准确率从 97.37% 一路降到 87.25%。原因是同样的 15 轮里，batch_size=8 时每轮更新 100 次参数（共 1500 次），batch_size=256 时每轮只更新 4 次（共 60 次）——更新次数差了 25 倍，大批量"还没学够"。这印证了规律：**在相同轮数下，小批量往往训练得更充分**；代价是每轮耗时更长、梯度噪声更大。看到"批量越大、准确率越低"的单调趋势，说明实验做对了。
- **实验二**：固定 lr=0.5 得到 96.50%，加上 StepLR 衰减后提升到 98.25%，差距 1.75 个百分点。lr=0.5 对这个任务偏大，固定学习率会在最优点附近震荡、停不稳；衰减后后期步长变小（0.5→0.25→0.125），能稳稳落进更优的位置。看到"衰减组高于固定组"，说明你理解了学习率衰减"前期探索、后期精调"的价值。
- **实验三**：6 组组合呈明显的规律：
  - 横向看，无论 bs=16 还是 64，**lr 越大准确率越高**（85.12%→95.63%→98.00%，78.50%→89.63%→98.12%），说明 15 轮内这个任务需要偏大的学习率才能收敛到位，0.01 太小、还没走到就停了；
  - 纵向看，相同 lr 下 bs=16 均好于 bs=64，与实验一的结论一致；
  - 最优组合是 `(64, 0.5)`，准确率 98.12%——注意它略高于同为 lr=0.5 的 `(16, 0.5)` 的 98.00%，说明批量适中时大批量的一点"稳定性红利"开始显现。
- **总体**：三组实验的数值趋势都能用概念部分讲的规律解释，没有出现反常结果。如果你在复现时看到完全相同的数字，说明环境、种子、代码都没有问题。

## 小结

- 超参数（学习率、批量大小、轮数等）不能靠梯度下降学到，只能靠实验对比来选择。
- 相同轮数下，小批量更新次数多、训练更充分，但噪声大、耗时长；大批量稳定但容易"学不够"。
- `StepLR(optimizer, step_size=5, gamma=0.5)` 实现阶梯式学习率衰减：每 5 轮 lr 减半。衰减让训练"前期大步探索、后期小步精调"，通常优于固定学习率。
- 网格搜索就是"候选值笛卡尔积 + 逐个训练 + 取最优"，用两层循环加一个字典即可手写；`max(results, key=results.get)` 是"按值找键"的标准写法。
- 组合数大时网格搜索代价高，贝叶斯优化（如 Optuna）能用更少试验找到相近甚至更优的组合，思想是"根据历史结果预测下一组该试哪里"。
