## 核心概念讲解

**回归与分类。** 分类的输出是"哪个类别"（离散），损失用交叉熵，指标看准确率/精确率/召回率；回归的输出是"多少"（连续），损失用均方误差 MSE，指标看 MAE/RMSE/R²。本章的房价就是一个典型的回归目标。

**EDA 与相关系数。** 拿到数据先别急着建模：逐特征看取值范围（有没有脏数据），再算每个特征与目标的皮尔逊相关系数（-1~+1，正号正相关、负号负相关、接近 0 则线性关系弱）。注意两个陷阱：① 相关系数衡量的是"该特征的波动能解释目标波动的多少份额"，系数小但方差小的特征（如卧室数）相关性会被大特征（面积）"淹没"，**相关性低 ≠ 特征没用**；② 相关系数只能发现**线性**关系，"120㎡ 以上才加价"这种转折它看不出来。

**数据泄漏（Data Leakage）。** 标准化的均值/标准差如果拿全量数据计算，验证集和测试集的信息就提前"漏"进了预处理，评估会虚高。正确做法：**先划分，统计量只从训练集算，验证/测试集套用**。一个自检技巧：验证集标准化后的均值不会恰好为 0——恰好为 0 反而说明拿全量算了统计量。

**标签缩放与逆变换。** 分类的标签是 0/1，回归的标签可能是几百万元——网络初始输出接近 0，第一个 loss 高达几十万，梯度剧烈震荡。所以标签也要标准化（减均值除标准差），让网络在"均值 0、标准差 1"的舒适区学习；预测完再用 `预测值 × y_std + y_mean` 变回万元。**评估指标必须在业务尺度上计算**，否则没法向业务方汇报。

**线性基线与 MLP。** 工程习惯：先用最简单的模型立一条"及格线"。线性回归 `y = Wx + b` 就是一个 `nn.Linear(5, 1)`——只有 6 个参数的迷你神经网络。它能学会所有线性规律，但拟合不了"120㎡ 处拐弯"的溢价：一根直线只能给面积取一个折中系数。MLP 里的每个 ReLU 神经元是一台"折点制造机"（`max(0, x)` 的图像在 0 处拐弯），32 个神经元就能拼出带多个拐点的分段曲线，轻松吃下这个非线性转折。

**最佳模型存档。** 只记录"最佳验证 loss 的数字"而不保存参数是常见 bug——训练结束后内存里剩的是最后一轮的模型，不是最好的那一轮。正确做法：验证创新高时把 `state_dict` **clone** 存档，训练结束 `load_state_dict` 恢复，之后才被允许碰测试集。

**回归三大指标。** MAE（平均绝对误差）：平均每套估错多少万，业务方听得懂；RMSE（均方根误差）：平方放大大误差，**恒 ≥ MAE**，差距越大说明离谱预测越多；R²（决定系数）：1 - 误差平方和/目标方差和，1 完美、0 等价于只会猜均价。多个指标互相校验还能抓 bug——RMSE < MAE 一定是指标代码写错了。

**绝对误差与相对误差。** 错 13 万对 300 万的房子是 4.4%，对 750 万的房子只有 1.7%。噪声是"等额"的（±15 万不分贵贱），所以低价段的相对误差天然更高——汇报时要说清口径。

**打包保存与上线。** 上线交付的不只是模型参数，还有全部预处理统计量（`x_mean/x_std/y_mean/y_std`）——新数据必须用训练时的同一套统计量做标准化，否则模型吃错了输入。`torch.save` 一个字典全部打包。推理链路：原始特征 → 标准化 → 模型 → 逆变换 → 报价。

## 完整代码

```python
"""
第 13 章：生活场景实战 —— 二手房房价预测（回归任务端到端案例）
对应赛项知识点：构建结构化数据集；监督学习的应用场景；
对智能系统进行测试和训练并编写报告
任务：根据面积、房龄、楼层、距地铁距离、卧室数 5 个特征预测房屋总价（连续值）
流程：业务分析 → 数据探索(EDA) → 划分与标准化 → 线性基线 → 神经网络
      → 测试集终评 → 误差分析 → 模型保存与上线推理
"""
import torch  # 导入 PyTorch
import torch.nn as nn  # 神经网络模块
from torch.utils.data import DataLoader, TensorDataset  # 数据工具

torch.manual_seed(42)  # 固定随机种子，保证结果可复现

# ========== 步骤 1：业务分析 + 构造数据 ==========
# 业务问题：中介如何根据一套房的基本信息快速估算合理价格？
# 问题翻译：输入 5 个特征、输出一个连续数值 —— 典型的"回归"任务
n = 2000  # 模拟 2000 条房源记录

area  = torch.rand(n) * 120 + 40            # 面积：40~160 ㎡，均匀分布
age   = torch.rand(n) * 30                  # 房龄：0~30 年
floor = torch.randint(1, 34, (n,)).float()  # 楼层：1~33 层的整数
dist  = torch.rand(n) * 2.9 + 0.1           # 距地铁：0.1~3.0 公里
rooms = torch.randint(1, 6, (n,)).float()   # 卧室数：1~5 间
X = torch.stack([area, age, floor, dist, rooms], dim=1)  # 拼成特征矩阵 (2000, 5)：每行一套房

# 人为设定的"市场定价规律"（万元）——现实中它藏在数据里，模型的任务就是从数据中学会它
premium = (area - 120).clamp(min=0) * 1.5   # 超过 120㎡ 的大户型额外溢价（这是非线性项！）
y = (area * 4.5        # 面积是价格主力：每平方米约 4.5 万
     - age * 2.0       # 房龄折旧：每老一年约贬 2 万
     + floor * 0.3     # 楼层高一点略加分
     - dist * 20.0     # 离地铁越远越便宜：每公里减 20 万
     + rooms * 5.0     # 每多一间卧室加 5 万
     + premium         # 大户型溢价
     + 120)            # 基础价 120 万
y = y + torch.randn(n) * 15  # 叠加标准差 15 万的市场噪声（同小区同房型成交价也不同）

feature_names = ["面积", "房龄", "楼层", "距地铁", "卧室数"]  # 特征名，后面打印报告用
print(f"步骤 1 数据构造完成：X={tuple(X.shape)}（{n} 套房 × 5 个特征），y={tuple(y.shape)}")

# ========== 步骤 2：探索性数据分析（EDA）——先看数据再建模 ==========
print("\n步骤 2 各特征统计：")
for i, name in enumerate(feature_names):  # 逐特征检查取值范围是否合理
    col = X[:, i]  # 取出第 i 列（所有房源的该特征）
    print(f"  {name}: 最小 {col.min():.2f} | 最大 {col.max():.2f} | 均值 {col.mean():.2f} | 标准差 {col.std():.2f}")
print(f"  房价: 最小 {y.min():.2f} | 最大 {y.max():.2f} | 均值 {y.mean():.2f} | 标准差 {y.std():.2f}")

print("步骤 2 各特征与房价的相关系数（+ 正相关 / - 负相关 / 接近 0 弱线性相关）：")
for i, name in enumerate(feature_names):
    corr = torch.corrcoef(torch.stack([X[:, i], y]))[0, 1]  # 皮尔逊相关系数，取值 [-1, 1]
    print(f"  {name}: {corr:+.4f}")

# ========== 步骤 3：划分数据集 + 标准化（统计量只用训练集，防数据泄漏） ==========
idx = torch.randperm(n)  # 把 0~1999 的序号随机打乱
train_idx, val_idx, test_idx = idx[:1400], idx[1400:1700], idx[1700:]  # 70% 训练 / 15% 验证 / 15% 测试
X_train, y_train = X[train_idx], y[train_idx]  # 用同一组序号同时索引 X 和 y，保证一一对应
X_val,   y_val   = X[val_idx],   y[val_idx]
X_test,  y_test  = X[test_idx],  y[test_idx]

x_mean, x_std = X_train.mean(dim=0), X_train.std(dim=0)  # 关键：只在训练集上算，验证/测试集套用
y_mean, y_std = y_train.mean(), y_train.std()            # 标签也要缩放（房价几百万，直接回归 loss 巨大）
X_train = (X_train - x_mean) / x_std  # 训练集 Z-score 标准化
X_val   = (X_val   - x_mean) / x_std  # 验证集套用【训练集】的统计量
X_test  = (X_test  - x_mean) / x_std  # 测试集同理
y_train_s = (y_train - y_mean) / y_std  # 标签标准化（_s 表示 scaled）
y_val_s   = (y_val   - y_mean) / y_std
# y_test 故意不标准化：最终评估必须在"万元"的业务尺度上进行

train_loader = DataLoader(TensorDataset(X_train, y_train_s), batch_size=64, shuffle=True)  # 训练：打乱
val_loader   = DataLoader(TensorDataset(X_val,   y_val_s),   batch_size=256)               # 验证：不打乱
print(f"\n步骤 3 划分+标准化完成：训练 {len(X_train)} / 验证 {len(X_val)} / 测试 {len(X_test)}")
print(f"  训练集特征均值（应≈0）: {X_train.mean(dim=0)}")
print(f"  验证集特征均值（不恰好为 0，恰是没有数据泄漏的证明）: {X_val.mean(dim=0)}")

# ========== 步骤 4：通用训练函数（带最佳参数存档）+ 训练两个模型 ==========
criterion = nn.MSELoss()  # 回归任务的标准损失：均方误差（分类用交叉熵，回归用 MSE）

def train_model(model, epochs=300):
    """通用训练循环：验证创新高时把参数复制存档，结束后恢复到最佳那一轮"""
    optimizer = torch.optim.Adam(model.parameters(), lr=0.01)  # 优化器绑定模型参数，函数内新建
    best_loss, best_state = float("inf"), None  # 回归比"谁 loss 小"，初值设无穷大
    for epoch in range(epochs):
        model.train()  # 训练模式
        for bx, by in train_loader:  # 训练五步曲
            loss = criterion(model(bx).squeeze(1), by)  # squeeze(1)：(64,1)->(64,)，回归经典形状坑
            optimizer.zero_grad()  # 清梯度
            loss.backward()  # 反向传播
            optimizer.step()  # 更新参数
        model.eval()  # 评估模式
        with torch.no_grad():  # 验证集按样本数加权求整体 MSE（最后一批可能不满）
            val_loss = sum(criterion(model(bx).squeeze(1), by).item() * len(bx)
                           for bx, by in val_loader) / len(X_val)
        if val_loss < best_loss:  # 验证表现创新高
            best_loss = val_loss
            best_state = {k: v.clone() for k, v in model.state_dict().items()}  # 复制存档，必须 clone
    model.load_state_dict(best_state)  # 训练结束恢复到最佳那一轮，而不是停在最后一轮
    return best_loss

torch.manual_seed(42)  # 训练前重置种子：建模型→训练的随机序列完全可控、可复现
linear_model = nn.Linear(5, 1)  # 基线：线性回归 = 没有隐藏层的迷你神经网络（仅 6 个参数）
linear_best = train_model(linear_model)
print(f"\n步骤 4 线性回归：参数量 {sum(p.numel() for p in linear_model.parameters())} | 最佳验证loss={linear_best:.4f}")

torch.manual_seed(42)  # 同样重置，保证 MLP 的训练也可复现
mlp = nn.Sequential(  # 神经网络：每个 ReLU 是一个"折点"，能拟合 120㎡ 溢价这种非线性转折
    nn.Linear(5, 32),   # 输入 5 -> 隐藏层 32
    nn.ReLU(),          # 非线性激活（没有它，多层线性叠起来仍是一条直线）
    nn.Linear(32, 16),  # 32 -> 16
    nn.ReLU(),          # 非线性激活
    nn.Linear(16, 1),   # 16 -> 1 个价格
)
mlp_best = train_model(mlp)
print(f"步骤 4 MLP：     参数量 {sum(p.numel() for p in mlp.parameters())} | 最佳验证loss={mlp_best:.4f}")
print(f"         理论下限：{(15.0 / y_std) ** 2:.4f}（噪声决定的极限，任何模型都突破不了）")

# ========== 步骤 5：测试集终评（MAE / RMSE / R²） ==========
def predict(model, X_data):
    """推理 + 逆变换回万元尺度（指标必须用业务尺度报告）"""
    model.eval()  # 评估模式
    with torch.no_grad():  # 关闭梯度，省内存提速
        return model(X_data).squeeze(1) * y_std + y_mean  # 标准化尺度 → 万元

def evaluate_regression(name, pred, true):
    """回归三大指标：MAE 平均估错多少万；RMSE 严惩大误差（恒≥MAE）；R² 解释了多少价格波动"""
    mae  = (pred - true).abs().mean()                                          # 平均绝对误差
    rmse = ((pred - true) ** 2).mean().sqrt()                                  # 均方根误差：先平方再平均最后开方
    r2   = 1 - ((pred - true) ** 2).sum() / ((true - true.mean()) ** 2).sum()  # 决定系数，1=完美 0=猜均价
    print(f"  {name}: MAE={mae:.1f} 万 | RMSE={rmse:.1f} 万 | R²={r2:.4f}")

print("\n步骤 5 测试集最终报告（300 套从未参与任何训练决策的房子）：")
evaluate_regression("线性回归", predict(linear_model, X_test), y_test)
evaluate_regression("MLP     ", predict(mlp, X_test),          y_test)

# ========== 步骤 6：误差分析 —— 模型在哪些房子上失手？ ==========
pred_mlp = predict(mlp, X_test)  # 测试集预测价（万元）
errors = pred_mlp - y_test       # 每套房的带符号误差（正=估高了，负=估低了）

print("\n步骤 6 分价位段误差分析：")
for lo, hi in [(0, 350), (350, 500), (500, 650), (650, 1000)]:
    m = (y_test >= lo) & (y_test < hi)  # 布尔掩码挑出该价位段（逐元素与用 &，不能写 and）
    if m.any():
        mae_b = errors[m].abs().mean()                        # 绝对误差（万元）
        rel_b = (errors[m].abs() / y_test[m]).mean() * 100    # 相对误差（占房价的 %）
        print(f"  {lo}~{hi} 万: {m.sum().item():3d} 套 | 平均误差 {mae_b:.1f} 万 | 相对误差 {rel_b:.1f}%")

print("步骤 6 误差最大的 5 套房：")
top5 = errors.abs().argsort(descending=True)[:5]  # argsort 返回的是下标，按绝对误差从大到小取前 5
for i in top5:
    area_i = X_test[i][0] * x_std[0] + x_mean[0]  # 面积从标准化尺度逆变换回平米
    print(f"  第 {i.item():3d} 套: 面积 {area_i:.0f}㎡ | 真实 {y_test[i]:.1f} 万 | 预测 {pred_mlp[i]:.1f} 万 | 误差 {errors[i]:+.1f} 万")

# ========== 步骤 7：保存模型（含预处理统计量）+ 模拟上线推理 ==========
torch.save({
    "model_state": mlp.state_dict(),   # 最佳模型参数
    "x_mean": x_mean, "x_std": x_std,  # 特征标准化统计量（上线后新数据必须做同一套变换！）
    "y_mean": y_mean, "y_std": y_std,  # 标签统计量（预测完要逆变换回万元）
}, "house_pricing_model.pt")  # 一个文件打包交付
print("\n步骤 7 模型已保存到 house_pricing_model.pt（参数 + 预处理统计量打包）")

ckpt = torch.load("house_pricing_model.pt")  # 模拟另一台机器上的上线程序：读回整个包
model_online = nn.Sequential(  # state_dict 只存参数不存结构，先搭一个结构相同的"空壳"
    nn.Linear(5, 32), nn.ReLU(), nn.Linear(32, 16), nn.ReLU(), nn.Linear(16, 1),
)
model_online.load_state_dict(ckpt["model_state"])  # 灌入保存的参数
model_online.eval()  # 上线永远是评估模式

new_house = torch.tensor([[89.0, 5.0, 12.0, 0.8, 3.0]])  # 一套新房：89㎡/5年房龄/12楼/0.8km/3室
x_new = (new_house - ckpt["x_mean"]) / ckpt["x_std"]     # 用保存的训练集统计量做标准化
with torch.no_grad():
    price = model_online(x_new).squeeze() * ckpt["y_std"] + ckpt["y_mean"]  # 预测 + 逆变换回万元
print(f"  上线估价：89㎡/5年房龄/12楼/距地铁0.8km/3室 → {price:.1f} 万"
      f"（对照公式价 {89*4.5 - 5*2 + 12*0.3 - 0.8*20 + 3*5 + 120:.1f} 万，89㎡ 不到 120 无溢价）")
```

### 文件头与导入

```python
import torch  # 导入 PyTorch
import torch.nn as nn  # 神经网络模块
from torch.utils.data import DataLoader, TensorDataset  # 数据工具

torch.manual_seed(42)  # 固定随机种子，保证结果可复现
```

- 与前面各章相同。注意本章**不需要** `random_split`——因为我们要在划分之前先拿到原始数据算训练集统计量，改用 `randperm` 手动切分（步骤 3 详解）。

### 步骤 1：业务分析 + 构造数据

```python
area  = torch.rand(n) * 120 + 40            # 面积：40~160 ㎡，均匀分布
age   = torch.rand(n) * 30                  # 房龄：0~30 年
floor = torch.randint(1, 34, (n,)).float()  # 楼层：1~33 层的整数
dist  = torch.rand(n) * 2.9 + 0.1           # 距地铁：0.1~3.0 公里
rooms = torch.randint(1, 6, (n,)).float()   # 卧室数：1~5 间
X = torch.stack([area, age, floor, dist, rooms], dim=1)  # 拼成特征矩阵 (2000, 5)
```

- `torch.rand(n) * 120 + 40` —— `rand` 生成 0~1 的均匀随机数，乘 120 加 40 平移缩放到 40~160。这是"把随机数映射到业务取值范围"的常用手法。
- `torch.randint(1, 34, (n,))` —— 生成 1~33 的**整数**（楼层、卧室数不能是小数），`.float()` 转成浮点型，因为神经网络只接受浮点输入。
- `torch.stack(..., dim=1)` —— 把 5 个长度 2000 的向量沿列方向拼成 `(2000, 5)`：**每行一套房、每列一个特征**，这是所有表格数据的标准形状。

```python
premium = (area - 120).clamp(min=0) * 1.5   # 超过 120㎡ 的大户型额外溢价（这是非线性项！）
y = (area * 4.5 - age * 2.0 + floor * 0.3 - dist * 20.0 + rooms * 5.0 + premium + 120)
y = y + torch.randn(n) * 15  # 叠加标准差 15 万的市场噪声
```

- `(area - 120).clamp(min=0)` —— `clamp(min=0)` 把负数截断为 0，效果等同 `max(0, x)`：面积不到 120㎡ 溢价为 0，超过的部分每平米加 1.5 万。这个"转折点"是**非线性**的，一根直线表达不了——它是本章线性模型与神经网络差距的来源，也是后面所有故事的伏笔。
- 定价公式各项都有业务含义：面积主力 4.5 万/㎡、房龄折旧 2 万/年、楼层微调、地铁距离每公里 -20 万、卧室每间 +5 万、基础价 120 万。
- `torch.randn(n) * 15` —— 标准差 15 万的正态噪声。没有噪声的数据太完美、不真实；噪声同时决定了任何模型的**理论误差下限**（步骤 4 会用到）。

### 步骤 2：探索性数据分析（EDA）

```python
for i, name in enumerate(feature_names):
    col = X[:, i]  # 取出第 i 列
    print(f"  {name}: 最小 {col.min():.2f} | ...")
```

- `X[:, i]` —— 逗号前 `:` 取全部 2000 行，逗号后取第 `i` 列，得到长度 2000 的向量。
- `col.min()` 等统计方法返回标量张量，`f"{...:.2f}"` 格式化保留两位小数。

```python
corr = torch.corrcoef(torch.stack([X[:, i], y]))[0, 1]  # 皮尔逊相关系数
```

- `torch.stack([X[:, i], y])` —— 把"某特征"和"房价"叠成 `(2, 2000)`，`corrcoef` 要求每**行**是一个变量。
- 返回 `(2, 2)` 相关矩阵：对角线是自己与自己的相关（恒为 1），`[0, 1]` 位置就是该特征与房价的相关系数。
- 解读标尺：|r| > 0.7 强相关，0.3~0.7 中等，< 0.1 弱。运行结果中面积 +0.98 是绝对主力；房龄、距地铁为负相关（越老/越远越便宜）；楼层、卧室数接近 0——不是没用，而是它们的波动份额被面积（4.5 万 × 标准差 34.5 ≈ 155 万）淹没了。

### 步骤 3：划分数据集 + 标准化

```python
idx = torch.randperm(n)  # 把 0~1999 的序号随机打乱
train_idx, val_idx, test_idx = idx[:1400], idx[1400:1700], idx[1700:]
X_train, y_train = X[train_idx], y[train_idx]
```

- 本章不用 `random_split`，而是**手动切分**：因为必须先拿到训练子集来算统计量。`randperm` 生成随机排列的序号，切片成 1400/300/300 三份。
- 用**同一组序号**同时索引 X 和 y，保证特征与标签一一对应——这是手动切分相对 `random_split` 要多操的一份心。

```python
x_mean, x_std = X_train.mean(dim=0), X_train.std(dim=0)  # 关键：只在训练集上算
X_val   = (X_val   - x_mean) / x_std  # 验证集套用【训练集】的统计量
```

- 本章最重要的工程细节：**统计量只从训练集计算**。若用全量数据算，测试集信息提前泄漏进预处理，评估虚高（第 10 章"先标准化再划分"的写法严格说有轻微泄漏，本章是规范做法）。
- 自检：运行结果中验证集标准化后的均值是 `[0.0066, 0.0824, ...]` 而不恰好为 0——因为它是"拿别人的统计量"标准化的。若恰好为 0，反而说明泄漏了。

```python
y_mean, y_std = y_train.mean(), y_train.std()            # 标签也要缩放
y_train_s = (y_train - y_mean) / y_std
# y_test 故意不标准化
```

- 回归特有的新步骤：房价均值 536 万，直接回归会导致初始 loss 高达几十万、梯度剧烈震荡。标签标准化后网络在"均值 0、标准差 1"的舒适区学习。
- `y_test` 不缩放：最终评估要在"万元"尺度上进行，预测值逆变换后与原始的 `y_test` 直接比较。

### 步骤 4：通用训练函数 + 两个模型

```python
criterion = nn.MSELoss()  # 回归任务的标准损失：均方误差
```

- MSE = 所有样本 (预测-真实)² 的平均：误差越大惩罚越狠，正负误差一视同仁。**直觉标尺**：标签标准化后方差为 1，只会猜均值的模型 MSE≈1，loss 降到 0.01 以下说明模型解释了约 99% 的价格波动。

```python
def train_model(model, epochs=300):
    optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
    ...
    loss = criterion(model(bx).squeeze(1), by)  # squeeze(1)：(64,1)->(64,)
```

- 把训练循环封装成函数，两个模型复用——第 10 章的函数化思想。
- `optimizer` 必须在函数内新建：它通过 `model.parameters()` 绑定具体模型的参数。
- **`.squeeze(1)` 是回归任务最经典的坑**：模型输出 `(64, 1)` 而标签是 `(64,)`，直接相减会触发广播变成 `(64, 64)`——不报错、loss 也降，但学的东西完全错误。必须 squeeze 对齐形状。

```python
        if val_loss < best_loss:
            best_loss = val_loss
            best_state = {k: v.clone() for k, v in model.state_dict().items()}
    model.load_state_dict(best_state)  # 恢复到最佳那一轮
```

- 另一个隐蔽坑：只记"最佳 loss 的数字"不存参数，训练结束后内存里是**最后一轮**而非**最好一轮**的模型（验证 loss 在 0.008~0.011 间波动，差距不小）。创新高时把 `state_dict` 逐项 **clone** 存档（不 clone 存的是引用，会继续被训练改掉），结束后 `load_state_dict` 恢复——这与第 10 章 `torch.save` 到磁盘是同一思想，只是存档在内存里。

```python
linear_model = nn.Linear(5, 1)  # 基线：仅 6 个参数
mlp = nn.Sequential(nn.Linear(5, 32), nn.ReLU(), nn.Linear(32, 16), nn.ReLU(), nn.Linear(16, 1))
```

- 线性回归 = 没有隐藏层、没有激活函数的迷你神经网络，`y = Wx + b` 共 6 个参数。先立"及格线"。
- MLP 参数量 737（手算：5×32+32=192，32×16+16=528，16×1+1=17）。每个 ReLU 是一个"折点"，32 个神经元足以拼出拟合 120㎡ 溢价转折的分段曲线。
- 两个模型训练前都 `torch.manual_seed(42)`：**重置种子让"建模型→训练"的随机序列完全可控**，结果可复现。

```python
print(f"         理论下限：{(15.0 / y_std) ** 2:.4f}（噪声决定的极限...）")
```

- 噪声标准差 15 万，换算到标准化尺度的 MSE 下限是 `(15/y_std)² ≈ 0.0076`。噪声本身不可预测，**任何模型都不可能比这个 loss 更低**——知道下限在哪，就不会做无谓的调参。

### 步骤 5：测试集终评

```python
def predict(model, X_data):
    model.eval()
    with torch.no_grad():
        return model(X_data).squeeze(1) * y_std + y_mean  # 逆变换回万元
```

- 模型输出是标准化尺度的数字，`* y_std + y_mean` 逆变换回万元。**指标必须用业务尺度报告**——"误差 0.07" 业务方听不懂，"平均估错 12 万"才听得懂。

```python
def evaluate_regression(name, pred, true):
    mae  = (pred - true).abs().mean()
    rmse = ((pred - true) ** 2).mean().sqrt()
    r2   = 1 - ((pred - true) ** 2).sum() / ((true - true.mean()) ** 2).sum()
```

- MAE：平均每套估错多少万，最直观的业务语言。
- RMSE：先平方、再平均、最后开方。平方放大了大误差的权重，**恒 ≥ MAE**；两者差距越大，说明离谱预测越多。注意括号顺序——先对带符号误差求平均再平方是常见笔误，正负误差抵消会得到接近 0 的假 RMSE；用"RMSE ≥ MAE"这条恒等式可以自检。
- R²：分母是"只会猜均价"模型的误差平方和。R²=1 完美，R²=0 等价于猜均价，负数比猜均价还差。它与步骤 4 的"标准化 loss≈1 就是猜均值"是同一把标尺。

### 步骤 6：误差分析

```python
for lo, hi in [(0, 350), (350, 500), (500, 650), (650, 1000)]:
    m = (y_test >= lo) & (y_test < hi)  # 布尔掩码挑出该价位段
```

- 布尔掩码的第 10 章老用法；`&` 是逐元素与，不能写成 Python 的 `and`。
- 同时报**绝对误差**（万）和**相对误差**（%）：噪声是等额的 ±15 万，所以低价段相对误差天然更高（4.4% vs 1.7%）——汇报口径要讲清。

```python
top5 = errors.abs().argsort(descending=True)[:5]  # argsort 返回下标
area_i = X_test[i][0] * x_std[0] + x_mean[0]  # 面积逆变换回平米
```

- `argsort` 返回**下标**而非数值——拿到下标才能回查这些房子的特征，侦探要的是案发现场。
- 标准化的逆运算 `x * std + mean`，把面积翻译回平米。

- 误差分析结论：误差最大的 5 套房面积各异、全是普通户型，误差 ±38~43 万 ≈ 噪声的 ±3σ 长尾——**是运气不是模型失败**。模型学规律，噪声不可学。真实业务中若失手样本有共同特征（如都是顶楼），则说明特征表漏了信息，该去找业务方补数据——这就是特征工程的入口。

### 步骤 7：保存模型 + 模拟上线

```python
torch.save({
    "model_state": mlp.state_dict(),
    "x_mean": x_mean, "x_std": x_std,
    "y_mean": y_mean, "y_std": y_std,
}, "house_pricing_model.pt")
```

- **打包的不只是参数，还有全部预处理统计量**。上线后新数据必须用训练时的同一套统计量做标准化——一套新房没有"均值"可算。只存参数不存统计量，是新手上线最常犯的错误。

```python
model_online = nn.Sequential(...)  # 先搭结构相同的"空壳"
model_online.load_state_dict(ckpt["model_state"])
model_online.eval()
```

- `state_dict` 只存参数不存结构，必须先 new 一个结构完全相同的空模型再灌参数；结构对不上会直接报错，这也是一种保护。
- 上线标配：`eval()` 模式 + `torch.no_grad()`。

```python
new_house = torch.tensor([[89.0, 5.0, 12.0, 0.8, 3.0]])  # 形状 (1, 5)
x_new = (new_house - ckpt["x_mean"]) / ckpt["x_std"]
price = model_online(x_new).squeeze() * ckpt["y_std"] + ckpt["y_mean"]
```

- 两层中括号：模型永远期待 `(批次, 特征)` 的二维输入，一套房也是"含 1 套的批次"。写成一层括号 `(5,)` 是上线代码最常见的形状 bug。
- 完整推理链路：原始特征 → 标准化 → 模型 → 逆变换 → 万元报价，这就是"特征工程管道（pipeline）"的最小形态。

## 小结

- 回归与分类的流程骨架相同，差异在三处：损失用 MSELoss、标签要缩放并逆变换、指标用 MAE/RMSE/R²。
- 标准化的统计量只能用训练集计算（防数据泄漏）；标签缩放是回归特有的必修课。
- 先用线性回归立"及格线"，再上神经网络；ReLU 是"折点制造机"，非线性转折是线性模型过不去、MLP 轻松过的分水岭。
- 训练要存档"最佳那一轮"的参数（clone 的 state_dict），评估用恢复后的模型碰测试集。
- 多指标互相校验（如 RMSE ≥ MAE）能抓指标代码的 bug；误差分析负责回答"模型在哪里失手"，区分"模型不懂"与"样本运气差"。
- 上线交付 = 模型参数 + 预处理统计量打包；推理链路 = 标准化 → 模型 → 逆变换。

## 动手练习

1. **放大非线性**：把步骤 1 的溢价系数从 `* 1.5` 改成 `* 3.0`，重新运行。观察线性回归的 RMSE 明显变大而 MLP 依然贴近理论下限，体会"非线性越强，神经网络越值"。
2. **体验标签不缩放**：把 `y_train_s = (y_train - y_mean) / y_std` 改成 `y_train_s = y_train`（直接用万元训练），观察初始 loss 几十万、训练剧烈震荡的现象，理解步骤 3 标签缩放的意义。看完改回。
