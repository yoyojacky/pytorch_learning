# 第 7 章：网络结构优化 —— 对抗过拟合（Dropout / BatchNorm / 早停）

## 本章目标

- 理解什么是过拟合，以及为什么"训练准确率高"不等于"模型好"
- 学会用 `nn.BatchNorm1d` 做批归一化，让训练更稳定、更快
- 学会用 `nn.Dropout` 随机丢弃神经元，抑制过拟合
- 掌握"早停"（Early Stopping）机制：验证集不再进步就提前结束训练
- 理解 `model.train()` 与 `model.eval()` 两种模式的区别及其对 Dropout / BatchNorm 的影响

## 对应赛项知识点

本章对应"上海市人工智能训练师职业技能大赛"中"通过网络结构优化实现模型精度与效率平衡"这一考核要求：选手需要能够分析模型在训练集与验证集上的表现差异，判断过拟合，并通过调整网络结构（加归一化层、加 Dropout、收窄隐藏层、引入早停等）在不浪费算力的前提下提升模型的泛化能力。

## 核心概念讲解

**过拟合（Overfitting）**：模型把训练数据"背"了下来，包括其中的噪声，在训练集上表现很好，但遇到没见过的新数据（验证集、测试集）就表现变差。过拟合最容易在"样本少、模型大"的场景出现——本章刻意构造了只有 200 个样本、却用 128 个神经元的宽网络的场景。

**泛化（Generalization）**：模型在没见过的数据上也能表现良好的能力。训练的最终目标是泛化好，而不是训练集分数高。因此判断模型好坏要看**验证集**上的指标。

**Dropout（随机失活）**：训练过程中，每次前向传播都以概率 `p` 随机把一部分神经元的输出置零（"丢弃"），强迫网络不依赖某几个特定神经元，从而学到更稳健的特征。`nn.Dropout(p=0.5)` 表示每次随机丢弃 50% 的神经元。注意：**评估/预测时必须关闭 Dropout**（用 `model.eval()`），否则结果会随机抖动。

**BatchNorm（批归一化）**：把每一层的输出在一个批次内做归一化——减去均值、除以标准差，再通过可学习的缩放 `γ` 和偏移 `β` 还原表达能力，公式为：

```
y = γ · (x - μ_batch) / √(σ²_batch + ε) + β
```

好处是每层的输入分布稳定，梯度不容易爆炸或消失，可以用更大的学习率，训练更快更稳。BatchNorm 在训练时用的是**当前批次**的均值方差，评估时用**训练过程中累计的全局统计量**，所以同样依赖 `train()` / `eval()` 模式切换。

**早停（Early Stopping）**：训练时持续监控验证集指标，如果连续 `patience`（耐心值）轮都没有提升，就提前终止训练。这样既避免后面继续训练只会加重过拟合，也节省了训练时间（效率优化）。

**参数量与效率**：优化版模型把第二个隐藏层从 128 收窄到 64，参数量更少、计算更快，这也是"精度与效率平衡"的一部分——好模型不只是准，还要省资源。

## 完整代码

```python
"""
第 7 章：网络结构优化 —— 对抗过拟合（Dropout / BatchNorm / 早停）
对应赛项知识点：通过网络结构优化实现模型精度与效率平衡
"""
import torch  # 导入 PyTorch
import torch.nn as nn  # 神经网络模块
from torch.utils.data import DataLoader, TensorDataset, random_split  # 数据工具

torch.manual_seed(42)  # 固定随机种子

# ========== 1. 构造一个"容易过拟合"的场景：样本少、特征多 ==========
n = 200  # 只有 200 个样本
X = torch.randn(n, 20)  # 特征多达 20 维
y = ((X[:, 0] + X[:, 1]) > 0).long()  # 标签其实只与前 2 个特征有关，其余 18 维是噪声

train_set, val_set = random_split(TensorDataset(X, y), [160, 40])  # 划分训练/验证
train_loader = DataLoader(train_set, batch_size=32, shuffle=True)  # 训练加载器
val_loader = DataLoader(val_set, batch_size=32)  # 验证加载器

# ========== 2. 定义两个模型：朴素版 vs 优化版 ==========
plain = nn.Sequential(  # 朴素版：又宽又深，没有任何正则化
    nn.Linear(20, 128),  # 20 -> 128
    nn.ReLU(),  # 激活
    nn.Linear(128, 128),  # 128 -> 128
    nn.ReLU(),  # 激活
    nn.Linear(128, 2),  # 输出 2 类
)

optimized = nn.Sequential(  # 优化版：加入三种结构优化手段
    nn.Linear(20, 128),  # 20 -> 128
    nn.BatchNorm1d(128),  # 批归一化：把每层输出拉回标准分布，训练更稳定、更快
    nn.ReLU(),  # 激活
    nn.Dropout(p=0.5),  # Dropout：训练时随机"丢弃"50%神经元，防止过度依赖某些特征
    nn.Linear(128, 64),  # 收窄的隐藏层：128 -> 64（减少参数量 = 效率优化）
    nn.BatchNorm1d(64),  # 批归一化
    nn.ReLU(),  # 激活
    nn.Dropout(p=0.5),  # 再次 Dropout
    nn.Linear(64, 2),  # 输出层
)

# ========== 3. 训练函数（带"早停"机制） ==========
def train_model(model, epochs=100, patience=10):
    """训练模型，并在验证准确率不再提升时提前停止（早停 Early Stopping）"""
    optimizer = torch.optim.Adam(model.parameters(), lr=0.01)  # Adam 优化器
    criterion = nn.CrossEntropyLoss()  # 交叉熵损失
    best_val, wait = 0.0, 0  # best_val 记录最佳验证准确率；wait 记录多少轮没进步
    history = []  # 保存每轮 (训练准确率, 验证准确率) 供分析

    for epoch in range(epochs):  # 最多训练 epochs 轮
        model.train()  # 训练模式：Dropout 生效、BatchNorm 用批次统计
        for bx, by in train_loader:  # 逐批次
            loss = criterion(model(bx), by)  # 前向 + 损失
            optimizer.zero_grad()  # 清梯度
            loss.backward()  # 反向传播
            optimizer.step()  # 更新参数

        model.eval()  # 评估模式：Dropout 关闭、BatchNorm 用全局统计
        with torch.no_grad():  # 关闭梯度
            tr = (model(X[:160]).argmax(1) == y[:160]).float().mean().item()  # 训练准确率
            va = (model(X[160:]).argmax(1) == y[160:]).float().mean().item()  # 验证准确率
        history.append((tr, va))  # 记录

        if va > best_val:  # 验证准确率提升
            best_val, wait = va, 0  # 更新最佳值并重置等待计数
        else:  # 没有提升
            wait += 1  # 等待计数加 1
            if wait >= patience:  # 连续 patience 轮没进步
                print(f"  第 {epoch+1} 轮触发早停")  # 提前终止，避免继续过拟合
                break  # 跳出训练循环
    return best_val, history  # 返回最佳验证准确率和历史

# ========== 4. 对比实验 ==========
print("--- 朴素模型 ---")
plain_best, plain_his = train_model(plain)  # 训练朴素模型
print("--- 优化模型 ---")
opt_best, opt_his = train_model(optimized)  # 训练优化模型

print(f"\n朴素模型：训练准确率 {plain_his[-1][0]:.2%} / 验证准确率 {plain_best:.2%}")
print(f"优化模型：训练准确率 {opt_his[-1][0]:.2%} / 验证准确率 {opt_best:.2%}")
print("解读：判断好坏要看验证准确率而不是训练准确率；优化模型的验证准确率更高，")
print("      说明 BatchNorm + Dropout + 早停有效抑制了过拟合，泛化能力更强。")
```

### 第 1 部分：构造容易过拟合的数据

```python
n = 200  # 只有 200 个样本
X = torch.randn(n, 20)  # 特征多达 20 维
y = ((X[:, 0] + X[:, 1]) > 0).long()  # 标签其实只与前 2 个特征有关，其余 18 维是噪声
```

- `n = 200` —— 样本总数只有 200 个。样本少是过拟合的温床，这是本章故意设置的"困难场景"。
- `X = torch.randn(n, 20)` —— 生成形状为 `(200, 20)` 的特征矩阵，每个数来自标准正态分布（均值 0、标准差 1）。每行是一个样本，有 20 个特征。特征多而样本少，模型很容易"死记硬背"。
- `y = ((X[:, 0] + X[:, 1]) > 0).long()` —— 生成标签：`X[:, 0]` 和 `X[:, 1]` 是取所有样本的第 1、2 个特征（形状都是 `(200,)`），两者相加后判断是否大于 0，得到一个布尔张量（True/False），`.long()` 把它转成 0/1 的长整型，这就是二分类标签 `y`（形状 `(200,)`）。关键点：标签**只与前 2 个特征有关**，剩下 18 个特征是纯噪声——模型如果能抵抗住噪声的诱惑，说明正则化起作用了。

```python
train_set, val_set = random_split(TensorDataset(X, y), [160, 40])  # 划分训练/验证
train_loader = DataLoader(train_set, batch_size=32, shuffle=True)  # 训练加载器
val_loader = DataLoader(val_set, batch_size=32)  # 验证加载器
```

- `train_set, val_set = random_split(TensorDataset(X, y), [160, 40])` —— 先用 `TensorDataset(X, y)` 把特征和标签打包（取第 i 个样本时同时返回 `X[i]` 和 `y[i]`），再用 `random_split` 按 160 / 40 随机切成训练集和验证集。验证集的作用就是模拟"没见过的新数据"，专门用来检验泛化能力。
- `train_loader = DataLoader(train_set, batch_size=32, shuffle=True)` —— 训练数据加载器：每批取 32 个样本，`shuffle=True` 表示每轮（epoch，把全部训练数据过一遍叫一个 epoch）开始前打乱顺序，避免模型记住样本的排列规律。160 个样本 ÷ 32 = 5 个批次。
- `val_loader = DataLoader(val_set, batch_size=32)` —— 验证数据加载器。验证不需要打乱顺序，所以不传 `shuffle`。注意：本例后面评估时其实直接用张量切片算了准确率，这个 `val_loader` 定义了但没有被使用，属于演示标准流程的"备用件"，了解即可。

### 第 2 部分：定义两个模型

```python
plain = nn.Sequential(  # 朴素版：又宽又深，没有任何正则化
    nn.Linear(20, 128),  # 20 -> 128
    nn.ReLU(),  # 激活
    nn.Linear(128, 128),  # 128 -> 128
    nn.ReLU(),  # 激活
    nn.Linear(128, 2),  # 输出 2 类
)
```

- `plain = nn.Sequential(...)` —— 用 `nn.Sequential` 把各层按顺序串起来，数据从前到后依次流过每一层，调用 `plain(x)` 就自动完成整条前向传播。
- `nn.Linear(20, 128)` —— 全连接层，输入 20 维、输出 128 维，内部做 `y = xWᵀ + b`。输入张量形状 `(batch, 20)` → 输出 `(batch, 128)`。参数数量为 20×128 + 128 = 2688 个。
- `nn.ReLU()` —— 激活函数，`ReLU(x) = max(0, x)`，把负数压成 0。没有激活函数，多层线性叠加等价于一层，网络就学不到复杂规律。激活层本身没有可学习参数，不改变张量形状。
- `nn.Linear(128, 128)` —— 第二个隐藏层，128 → 128，形状不变。参数量 128×128 + 128 = 16512 个，是整个网络里参数最多的一层。
- `nn.ReLU()` —— 再次激活。
- `nn.Linear(128, 2)` —— 输出层，128 → 2，输出 2 个分数（logits），分别对应类别 0 和类别 1。注意输出的是"原始分数"而不是概率，概率交给损失函数内部处理。
- 整体评价：对 200 个样本来说，这个网络有一万多个参数，又宽又没有正则化，是典型的"容易过拟合"结构——这正是要拿来当对照组的"反面教材"。

```python
optimized = nn.Sequential(  # 优化版：加入三种结构优化手段
    nn.Linear(20, 128),  # 20 -> 128
    nn.BatchNorm1d(128),  # 批归一化：把每层输出拉回标准分布，训练更稳定、更快
    nn.ReLU(),  # 激活
    nn.Dropout(p=0.5),  # Dropout：训练时随机"丢弃"50%神经元，防止过度依赖某些特征
    nn.Linear(128, 64),  # 收窄的隐藏层：128 -> 64（减少参数量 = 效率优化）
    nn.BatchNorm1d(64),  # 批归一化
    nn.ReLU(),  # 激活
    nn.Dropout(p=0.5),  # 再次 Dropout
    nn.Linear(64, 2),  # 输出层
)
```

- `optimized = nn.Sequential(...)` —— 优化版模型，同样用 `Sequential` 串联，但在关键位置插入了 BatchNorm 和 Dropout，并收窄了中间层。
- `nn.Linear(20, 128)` —— 第一层与朴素版相同，保证对比公平（唯一的变量是"优化手段"本身）。
- `nn.BatchNorm1d(128)` —— 对 128 维输出做批归一化：在一个批次内把每个维度拉到均值 0、方差 1 附近，再乘可学习的 `γ`、加可学习的 `β`。数字 `128` 必须和上一层输出维度一致，否则报错。放在"线性层之后、激活函数之前"是常见做法。它让每层的输入分布稳定，训练更快、对学习率更不敏感。
- `nn.ReLU()` —— 激活。
- `nn.Dropout(p=0.5)` —— Dropout 层，训练时每个神经元有 50% 概率被置零，剩余被保留的会放大 1/(1-p) = 2 倍以维持整体量级。没有参数、不改变形状，只在 `model.train()` 模式下生效，`model.eval()` 下自动变成"直通"。
- `nn.Linear(128, 64)` —— 把隐藏层从 128 收窄到 64。参数量 128×64 + 64 = 8256 个，比朴素版的 16512 少了一半，计算更快、过拟合空间更小——这是"精度与效率平衡"里的效率侧。
- `nn.BatchNorm1d(64)` —— 对 64 维输出再次批归一化。
- `nn.ReLU()` —— 激活。
- `nn.Dropout(p=0.5)` —— 再次 Dropout，继续压制对特定神经元的依赖。
- `nn.Linear(64, 2)` —— 输出层，64 → 2，同样输出 2 个类别的原始分数。

### 第 3 部分：带早停的训练函数

```python
def train_model(model, epochs=100, patience=10):
    """训练模型，并在验证准确率不再提升时提前停止（早停 Early Stopping）"""
```

- `def train_model(model, epochs=100, patience=10):` —— 定义通用训练函数，接收任意模型，默认最多训练 100 轮，`patience=10` 表示容忍连续 10 轮验证准确率不提升。两个模型复用同一个函数，保证对比实验条件一致。
- `"""..."""` —— 函数的 docstring，说明这个函数做什么、早停是什么。

```python
    optimizer = torch.optim.Adam(model.parameters(), lr=0.01)  # Adam 优化器
    criterion = nn.CrossEntropyLoss()  # 交叉熵损失
    best_val, wait = 0.0, 0  # best_val 记录最佳验证准确率；wait 记录多少轮没进步
    history = []  # 保存每轮 (训练准确率, 验证准确率) 供分析
```

- `optimizer = torch.optim.Adam(model.parameters(), lr=0.01)` —— 创建 Adam 优化器（一种自适应学习率的梯度下降算法，比赛中默认首选），`model.parameters()` 把模型的全部可学习参数交给它管理，`lr=0.01` 是初始学习率（每次参数更新的步长）。
- `criterion = nn.CrossEntropyLoss()` —— 交叉熵损失函数，二分类/多分类的标准选择。它内部自带 Softmax，所以模型输出原始分数即可，不要自己先过 Softmax（会重复计算，数值上也不稳定）。
- `best_val, wait = 0.0, 0` —— 一行同时初始化两个变量：`best_val` 记录目前为止最好的验证准确率，`wait` 记录已经连续多少轮没有超过它，这是早停机制的两个核心状态。
- `history = []` —— 空列表，用来存每一轮的 (训练准确率, 验证准确率) 元组，训练结束后可以回看整个过程。

```python
    for epoch in range(epochs):  # 最多训练 epochs 轮
        model.train()  # 训练模式：Dropout 生效、BatchNorm 用批次统计
        for bx, by in train_loader:  # 逐批次
            loss = criterion(model(bx), by)  # 前向 + 损失
            optimizer.zero_grad()  # 清梯度
            loss.backward()  # 反向传播
            optimizer.step()  # 更新参数
```

- `for epoch in range(epochs):` —— 外层循环，最多跑 100 轮；如果触发早停会提前 `break` 出去。
- `model.train()` —— 把模型切到**训练模式**。它本身不训练任何参数，作用是通知 Dropout"开始随机丢弃"、通知 BatchNorm"用当前批次的均值方差并更新全局统计"。忘记调用它，Dropout 和 BatchNorm 的行为就不对，是常见 bug 来源。
- `for bx, by in train_loader:` —— 内层循环，从加载器里逐批取数据：`bx` 是形状 `(32, 20)` 的特征批次（最后一批可能不足 32），`by` 是形状 `(32,)` 的标签批次。
- `loss = criterion(model(bx), by)` —— 一行完成前向传播和损失计算：`model(bx)` 输出形状 `(32, 2)` 的原始分数，`criterion` 与标签对比得到标量损失。损失越小说明预测越准。
- `optimizer.zero_grad()` —— 把上一轮累积在参数上的梯度清零。PyTorch 默认梯度是**累加**的，不清零会把好几轮的梯度混在一起，是新手最常踩的坑之一。
- `loss.backward()` —— 反向传播，自动算出损失对每个参数的梯度，存到各参数的 `.grad` 属性里。
- `optimizer.step()` —— 优化器根据梯度真正更新所有参数，完成一次"学习"。上面三行 `zero_grad → backward → step` 是 PyTorch 训练的固定三步曲，顺序不能乱。

```python
        model.eval()  # 评估模式：Dropout 关闭、BatchNorm 用全局统计
        with torch.no_grad():  # 关闭梯度
            tr = (model(X[:160]).argmax(1) == y[:160]).float().mean().item()  # 训练准确率
            va = (model(X[160:]).argmax(1) == y[160:]).float().mean().item()  # 验证准确率
        history.append((tr, va))  # 记录
```

- `model.eval()` —— 切到**评估模式**：Dropout 关闭（所有神经元都参与，输出确定），BatchNorm 改用训练期间累计的全局均值方差。评估时不切模式，结果会每次随机波动，无法公平比较。
- `with torch.no_grad():` —— 上下文管理器，块内所有运算不记录梯度，省内存、省计算。只做预测/评估时都应该用它包起来。
- `tr = (model(X[:160]).argmax(1) == y[:160]).float().mean().item()` —— 计算训练准确率，拆解这条链式调用：`X[:160]` 取前 160 个样本（与训练集对应的切片）；`model(...)` 输出 `(160, 2)` 的分数；`.argmax(1)` 沿第 1 维（每个样本的 2 个类别分数）取较大者的下标，得到 `(160,)` 的预测类别；`== y[:160]` 逐元素比较得到布尔张量；`.float()` 把 True/False 变成 1.0/0.0；`.mean()` 求平均即准确率（0~1 的小数）；`.item()` 把单元素张量取出为 Python 数字，方便存储和打印。
- `va = (model(X[160:]).argmax(1) == y[160:]).float().mean().item()` —— 同样流程计算验证准确率，只不过用第 160 个之后的 40 个样本。注意这里用张量切片近似对应 `random_split` 划分出的验证集（因种子固定，实际划分一致），真实项目中更规范的做法是遍历 `val_loader`。
- `history.append((tr, va))` —— 把本轮的两个准确率以元组形式追加到历史列表，`history[-1]` 永远是最后一轮的记录。

```python
        if va > best_val:  # 验证准确率提升
            best_val, wait = va, 0  # 更新最佳值并重置等待计数
        else:  # 没有提升
            wait += 1  # 等待计数加 1
            if wait >= patience:  # 连续 patience 轮没进步
                print(f"  第 {epoch+1} 轮触发早停")  # 提前终止，避免继续过拟合
                break  # 跳出训练循环
    return best_val, history  # 返回最佳验证准确率和历史
```

- `if va > best_val:` —— 本轮验证准确率刷新了历史最佳。
- `best_val, wait = va, 0` —— 更新最佳值，同时把"连续没进步"的计数清零——一旦进步了，耐心就重新充满。
- `else:` —— 本轮没有进步。
- `wait += 1` —— 没进步的轮数加 1。
- `if wait >= patience:` —— 连续 10 轮都没能超越历史最佳，说明模型已经过了它的"巅峰期"，继续训练大概率只会更贴合训练集噪声（即过拟合加深）。
- `print(f"  第 {epoch+1} 轮触发早停")` —— 打印提示。`epoch` 从 0 开始计数，加 1 才是人类习惯的"第几轮"。
- `break` —— 跳出 `for epoch` 循环，训练提前结束。省下的轮次就是省下的时间和算力。
- `return best_val, history` —— 返回最佳验证准确率和完整历史。注意返回的是**历史最佳** `best_val` 而不是最后一轮的 `va`——早停的思想就是"把巅峰时刻的模型留下"。（严谨的比赛中还会同时保存当时的模型权重，本章为简化省略了这一步。）

### 第 4 部分：对比实验

print("--- 朴素模型 ---")
plain_best, plain_his = train_model(plain)  # 训练朴素模型
print("--- 优化模型 ---")
opt_best, opt_his = train_model(optimized)  # 训练优化模型

- `print("--- 朴素模型 ---")` —— 打印分隔标题，让输出更易读。
- `plain_best, plain_his = train_model(plain)` —— 用默认参数（100 轮、耐心 10）训练朴素模型，把返回的两个值分别解包给 `plain_best`（最佳验证准确率）和 `plain_his`（历史列表）。
- `print("--- 优化模型 ---")` —— 打印第二个分隔标题。
- `opt_best, opt_his = train_model(optimized)` —— 用完全相同的超参数训练优化模型。除了网络结构，其它条件（数据、优化器、学习率、训练函数）全部一致，这才是一组公平的对比实验。

```python

```

- `print(f"\n朴素模型：训练准确率 {plain_his[-1][0]:.2%} / 验证准确率 {plain_best:.2%}")` —— f-string 格式化输出：`\n` 先换一行；`plain_his[-1][0]` 取历史最后一条记录的第 0 个元素，即**最后一轮**的训练准确率；`{...:.2%}` 把小数格式化成保留两位小数的百分数（如 0.9812 → `98.12%`）。
- `print(f"优化模型：训练准确率 ...")` —— 同样格式输出优化模型的两项指标。
- `print("解读：...")` 与下一行 `print("      ...")` —— 打印结论性解读：评价模型看验证准确率；优化模型验证准确率更高，说明三种手段共同抑制了过拟合。把结论直接打印出来，方便读者运行后立即对照理解。

## 运行结果与解读

```text
--- 朴素模型 ---
  第 12 轮触发早停
--- 优化模型 ---
  第 13 轮触发早停

朴素模型：训练准确率 98.12% / 验证准确率 97.50%
优化模型：训练准确率 98.75% / 验证准确率 100.00%
解读：判断好坏要看验证准确率而不是训练准确率；优化模型的验证准确率更高，
      说明 BatchNorm + Dropout + 早停有效抑制了过拟合，泛化能力更强。
```

逐项解读：

- `第 12 轮触发早停` / `第 13 轮触发早停` —— 两个模型都没有跑满 100 轮：朴素模型在第 12 轮、优化模型在第 13 轮时，已经连续 10 轮验证准确率没有刷新纪录，于是提前收工。看到这两行，说明你的早停逻辑工作正常。这也直观体现了早停的"效率"价值：该停就停，不浪费算力。
- `朴素模型：训练准确率 98.12% / 验证准确率 97.50%` —— 朴素模型训练集 98.12%、验证集 97.50%，验证略低于训练，已经出现轻微的过拟合苗头（训练分高、验证分低）。40 个验证样本的 97.50% 意味着答对了 39 个、错 1 个。
- `优化模型：训练准确率 98.75% / 验证准确率 100.00%` —— 优化模型两项都更高，且**验证准确率达到 100.00%**，40 个验证样本全部答对。注意它的训练准确率也比朴素版高，这说明 BatchNorm 让训练本身也更充分，而不是单纯"压训练分换验证分"。
- 两行解读文字 —— 本章的核心结论：评价模型好坏的标尺是**验证集**表现；在样本少、噪声特征多的困难场景下，BatchNorm + Dropout + 早停的组合让模型把宝贵的拟合能力用在了真正的规律（前 2 个特征）上，而不是 18 维噪声上，泛化能力更强。运行结果与这个预期完全吻合，说明实验做对了。

## 小结

- 过拟合 = 训练集表现好、新数据表现差；判断模型好坏永远看验证集指标。
- `nn.BatchNorm1d` 稳定每层输入分布，训练更快更稳；`nn.Dropout(p=0.5)` 训练时随机丢弃一半神经元，防止过度依赖个别特征。
- 收窄隐藏层（128→64）减少参数量，是"精度与效率平衡"中效率侧的常用手段。
- 早停：监控验证指标，连续 `patience` 轮不提升就 `break`，把巅峰时的成绩留下，还省训练时间。
- `model.train()` / `model.eval()` 必须成对正确切换，否则 Dropout 和 BatchNorm 行为错误；评估时记得加 `torch.no_grad()`。

## 动手练习

1. **关掉 Dropout 看差距**：把优化模型里的两个 `nn.Dropout(p=0.5)` 都注释掉再运行，对比验证准确率是上升还是下降，体会 Dropout 在这个小数据集上的作用。
2. **调整耐心值**：把 `train_model(plain)` 改成 `train_model(plain, patience=3)` 运行，观察早停触发轮次和最终验证准确率的变化，思考耐心值太小可能带来什么问题。
3. **加大噪声难度**：把特征数从 20 改成 50（`torch.randn(n, 50)`，同时两个模型的第一层输入维度也改成 50），噪声特征从 18 维变成 48 维，运行后比较两个模型验证准确率的差距是拉大还是缩小了。
