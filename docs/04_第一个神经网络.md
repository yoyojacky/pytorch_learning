## 核心概念讲解

### 监督学习与二分类

**监督学习**（supervised learning）是指：训练数据里每一条样本都自带“标准答案”，模型的任务是从中学出“输入 → 答案”的规律。本章构造了 500 个平面上的点，每个点有两个坐标（特征），答案是“这个点在半径 2 的圆内（类别 0）还是圆外（类别 1）”。只有两个类别，所以叫**二分类**。

关键难点在于：两类点的分界线是一个**圆**，而不是一条直线。一条直线无论如何也分不开“内圈”和“外圈”，这种问题叫**非线性可分**问题，必须借助带激活函数的多层网络才能解决。

### 多层感知机（MLP）

**多层感知机**（Multi-Layer Perceptron，MLP）是最基础的神经网络，由若干“全连接层”堆叠而成：

- **全连接层**（`nn.Linear`）：对输入做一次“加权求和再加偏置”，公式为 `y = xWᵀ + b`。输入 2 维、输出 16 维，就意味着层里有 16×2 个权重和 16 个偏置等待学习；
- **激活函数 ReLU**：`f(x) = max(0, x)`，把负数全部压成 0。它的作用是**引入非线性**——如果没有它，再多线性层叠起来也等价于一个线性变换，依然画不出圆形边界；
- **输出层**：最后一层输出 2 个数，分别代表“属于类别 0 的得分”和“属于类别 1 的得分”，得分高的类别就是模型的预测结果。这样的原始得分有个专门名字叫 **logits**。

数据流动方向：`输入(2维) → Linear(2,16) → ReLU → Linear(16,8) → ReLU → Linear(8,2) → 输出(2维得分)`。数据从输入流向输出的过程叫**前向传播**（forward）。

### 交叉熵损失与 softmax

**损失函数**用来衡量“预测离正确答案有多远”，训练的目标就是把它降到最小。分类任务的标准选择是**交叉熵损失**（`nn.CrossEntropyLoss`）。

直观理解交叉熵分两步：先把 2 个得分通过 **softmax** 变成两个加起来等于 1 的“概率”，再看正确类别分到的概率有多大——概率越接近 1，损失越接近 0；概率越小，损失越大。PyTorch 的 `CrossEntropyLoss` 内部已经包含了 softmax，所以网络输出层**不需要**自己再加 softmax（这是一个常见的新手坑）。

### SGD 优化器与学习率

**优化器**负责根据梯度更新参数。本章用 **SGD**（随机梯度下降，Stochastic Gradient Descent），更新规则是：

```
参数 ← 参数 - 学习率 × 梯度
```

**学习率**（learning rate，`lr`）决定每一步迈多大：太小则学得慢，太大则可能“迈过最低点”导致震荡不收敛。本章取 `lr=0.1`。

### 训练五步曲、epoch 与 batch

PyTorch 训练循环的核心是固定的五个步骤，背下来就能套用到几乎所有模型上：

1. 前向传播：`pred = model(batch_X)`；
2. 计算损失：`loss = criterion(pred, batch_y)`；
3. 清空梯度：`optimizer.zero_grad()`；
4. 反向传播算梯度：`loss.backward()`；
5. 更新参数：`optimizer.step()`。

两个常用术语（第一次出现，后面章节会反复用到）：

- **epoch（轮次）**：把全部训练数据完整过一遍，叫 1 个 epoch。本章训练 50 轮，即数据被反复学习了 50 遍；
- **batch（批次）**：数据量较大时不一次性全喂给模型，而是每次取一小撮（本章 32 条）算一次梯度、更新一次参数。500 条数据按每批 32 条切分，一轮要更新 16 次（前 15 批各 32 条，最后 1 批 20 条）。

## 完整代码

```python
"""
第 4 章：第一个神经网络（MLP 二分类）
对应赛项知识点：监督学习的应用场景；根据业务场景选择深度学习算法框架
"""
import torch  # 导入 PyTorch
import torch.nn as nn  # nn 模块提供网络层（Linear、ReLU 等）
from torch.utils.data import DataLoader, TensorDataset  # TensorDataset 快速封装张量数据集

torch.manual_seed(42)  # 固定随机种子

# ========== 1. 构造监督学习数据：两个同心圆二分类 ==========
n = 500  # 总样本数
X = torch.randn(n, 2) * 2  # 500 个二维点
radius = X[:, 0] ** 2 + X[:, 1] ** 2  # 每个点到原点的距离平方
y = (radius > 4).long()  # 距离平方 > 4 的为类别 1，否则为类别 0（非线性边界！）

dataset = TensorDataset(X, y)  # 用 TensorDataset 快速打包特征和标签
loader = DataLoader(dataset, batch_size=32, shuffle=True)  # 每批 32 条并打乱

# ========== 2. 定义神经网络 ==========
class MLP(nn.Module):  # 所有网络都要继承 nn.Module
    def __init__(self):  # 构造函数：定义网络有哪些层
        super().__init__()  # 调用父类构造函数（固定写法）
        self.layer1 = nn.Linear(2, 16)  # 全连接层：输入 2 维 -> 输出 16 维
        self.relu = nn.ReLU()  # 激活函数 ReLU：引入非线性，f(x)=max(0,x)
        self.layer2 = nn.Linear(16, 8)  # 全连接层：16 维 -> 8 维
        self.layer3 = nn.Linear(8, 2)  # 输出层：8 维 -> 2 维（两个类别的得分）

    def forward(self, x):  # forward 定义数据如何流过各层（前向传播）
        x = self.relu(self.layer1(x))  # 第 1 层 + ReLU
        x = self.relu(self.layer2(x))  # 第 2 层 + ReLU
        return self.layer3(x)  # 输出层（交叉熵损失自带 softmax，这里不加激活）

model = MLP()  # 实例化模型
print(model)  # 打印网络结构

# ========== 3. 定义损失函数与优化器 ==========
criterion = nn.CrossEntropyLoss()  # 交叉熵损失：分类任务的标准损失函数
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)  # SGD 优化器，学习率 0.1
# model.parameters() 把模型所有可学习参数交给优化器管理

# ========== 4. 训练循环（PyTorch 五步曲） ==========
for epoch in range(50):  # 训练 50 轮
    total_loss = 0.0  # 累计本轮总损失
    for batch_X, batch_y in loader:  # 逐批次取数据
        pred = model(batch_X)  # 第 1 步：前向传播，得到预测得分 (32, 2)
        loss = criterion(pred, batch_y)  # 第 2 步：计算损失
        optimizer.zero_grad()  # 第 3 步：清空上一轮的梯度
        loss.backward()  # 第 4 步：反向传播计算梯度
        optimizer.step()  # 第 5 步：优化器根据梯度更新参数
        total_loss += loss.item()  # .item() 取出标量值并累加

    if (epoch + 1) % 10 == 0:  # 每 10 轮评估一次
        with torch.no_grad():  # 评估时关闭梯度计算，节省内存
            acc = (model(X).argmax(dim=1) == y).float().mean()  # 预测类别与真实标签比较
        print(f"第 {epoch+1:2d} 轮 | 平均损失={total_loss/len(loader):.4f} | 准确率={acc:.2%}")
```

### 第 1 部分：构造监督学习数据

```python
n = 500  # 总样本数
X = torch.randn(n, 2) * 2  # 500 个二维点
```

- `n = 500` —— 设定样本总数为 500，即构造 500 个数据点；
- `X = torch.randn(n, 2) * 2` —— `torch.randn(500, 2)` 生成形状为 `(500, 2)` 的张量，每个数服从标准正态分布（均值 0、标准差 1）；整体乘以 2 把数据放大，让点散布得更开（标准差变为 2）。`X` 就是特征矩阵：**每一行是一个样本，两个数分别是横、纵坐标**。注意 Python 里 `*` 是对张量每个元素分别乘（标量广播），不是矩阵乘法。

```python
radius = X[:, 0] ** 2 + X[:, 1] ** 2  # 每个点到原点的距离平方
```

- `X[:, 0]` 取出所有样本的第 1 列（横坐标），形状 `(500,)`；`X[:, 1]` 取第 2 列（纵坐标）。`** 2` 是逐元素平方。两者相加得到每个点到原点的**距离平方**（注意：变量名叫 `radius`，实际存的是半径的平方，即 x²+y²），结果形状 `(500,)`，每个样本一个数。

```python
y = (radius > 4).long()  # 距离平方 > 4 的为类别 1，否则为类别 0（非线性边界！）
```

- `radius > 4` 做逐元素比较，得到布尔张量（True/False）；`.long()` 把 True 转成 1、False 转成 0。含义：距离平方大于 4（即点到原点距离超过 2）的点标为类别 1，其余标为类别 0。这样两类样本的分界线是一个**半径为 2 的圆**——直线分不开，属于非线性问题。
- 注意：标签类型必须是整型（long），因为后面的交叉熵损失要求标签是类别编号（整数），这是新手常踩的坑。

```python
dataset = TensorDataset(X, y)  # 用 TensorDataset 快速打包特征和标签
loader = DataLoader(dataset, batch_size=32, shuffle=True)  # 每批 32 条并打乱
```

- `TensorDataset(X, y)` —— 把特征 `X`（形状 `(500, 2)`）和标签 `y`（形状 `(500,)`）按行一一对应打包成一个数据集对象，之后可以用下标取出“第 i 条特征 + 第 i 个标签”；
- `DataLoader(dataset, batch_size=32, shuffle=True)` —— 创建数据加载器：每批取 32 条（`batch_size=32`），每轮开始前把数据顺序随机打乱（`shuffle=True`）。500 ÷ 32 = 15 余 20，所以一轮会产出 **16 个批次**，前 15 批各 32 条，最后一批 20 条。打乱顺序能避免模型记住数据的排列顺序，让训练更稳定。

### 第 2 部分：定义神经网络

```python
class MLP(nn.Module):  # 所有网络都要继承 nn.Module
    def __init__(self):  # 构造函数：定义网络有哪些层
        super().__init__()  # 调用父类构造函数（固定写法）
```

- `class MLP(nn.Module):` —— 定义一个名为 `MLP` 的类，**继承**自 `nn.Module`。在 PyTorch 里，所有自定义网络都必须继承 `nn.Module`，这样框架才能自动帮你管理参数、切换训练/评估模式、搬到 GPU 等；
- `def __init__(self):` —— 构造函数，创建对象时自动执行。约定俗成的分工是：**在 `__init__` 里声明网络有哪些层**；
- `super().__init__()` —— 调用父类 `nn.Module` 的构造函数，完成框架内部的初始化登记。这是**固定写法，不能省略**——少了它，后面注册的网络层不会被框架识别，训练和打印结构都会出错。

```python
        self.layer1 = nn.Linear(2, 16)  # 全连接层：输入 2 维 -> 输出 16 维
        self.relu = nn.ReLU()  # 激活函数 ReLU：引入非线性，f(x)=max(0,x)
        self.layer2 = nn.Linear(16, 8)  # 全连接层：16 维 -> 8 维
        self.layer3 = nn.Linear(8, 2)  # 输出层：8 维 -> 2 维（两个类别的得分）
```

- `self.layer1 = nn.Linear(2, 16)` —— 创建第 1 个全连接层：输入 2 维（正好对上每个样本的 2 个坐标），输出 16 维。它内部自动创建可学习的权重矩阵（形状 `(16, 2)`）和偏置向量（形状 `(16,)`），计算规则是 `输出 = 输入 × 权重转置 + 偏置`。**把层赋值给 `self.` 开头的属性，`nn.Module` 才会把它登记为网络的一部分**，这一点很关键；
- `self.relu = nn.ReLU()` —— 创建 ReLU 激活函数，`f(x) = max(0, x)`：正数原样通过，负数一律变成 0。它没有可学习参数，作用纯粹是引入非线性。注意这里只创建了一个 `relu` 对象，但在 `forward` 里被重复使用了两次——没有参数的层可以安全地复用；
- `self.layer2 = nn.Linear(16, 8)` —— 第 2 个全连接层：把 16 维压到 8 维。它接在 layer1 后面，所以输入维度必须等于上一层的输出维度 16，这是层与层之间**必须对齐**的地方，写错了会在前向传播时报矩阵形状不匹配的错误；
- `self.layer3 = nn.Linear(8, 2)` —— 输出层：8 维输入、2 维输出。输出 2 个数分别代表“类别 0 的得分”和“类别 1 的得分”（logits），**输出维度必须等于类别数**。到此，整个网络共有 3 组可学习参数：(2×16+16) + (16×8+8) + (8×2+2) = 48 + 136 + 18 = 202 个参数。

```python
    def forward(self, x):  # forward 定义数据如何流过各层（前向传播）
        x = self.relu(self.layer1(x))  # 第 1 层 + ReLU
        x = self.relu(self.layer2(x))  # 第 2 层 + ReLU
        return self.layer3(x)  # 输出层（交叉熵损失自带 softmax，这里不加激活）
```

- `def forward(self, x):` —— 定义前向传播方法。函数名**必须叫 `forward`**：以后写 `model(batch_X)` 时，PyTorch 会自动调用这个方法。参数 `x` 是输入数据，形状 `(batch大小, 2)`；
- `x = self.relu(self.layer1(x))` —— 先过 layer1：`(32, 2) → (32, 16)`，再过 ReLU 把负值清零。括号从内向外读：`layer1(x)` 的结果作为 `relu` 的输入；
- `x = self.relu(self.layer2(x))` —— 同样套路过第 2 层：`(32, 16) → (32, 8)`，再接 ReLU；
- `return self.layer3(x)` —— 过输出层：`(32, 8) → (32, 2)`，直接返回 2 个原始得分。**输出层后面不接 ReLU、也不接 softmax**：ReLU 会把负得分清零丢失信息；softmax 则已内置在交叉熵损失函数里，重复加反而让训练变差。这是本章最重要的一个细节。

```python
model = MLP()  # 实例化模型
print(model)  # 打印网络结构
```

- `model = MLP()` —— 创建模型实例。执行这一行时 `__init__` 被调用，三个全连接层和 ReLU 被创建，权重和偏置被随机初始化（受前面 `manual_seed(42)` 控制，所以每次初始化结果相同）；
- `print(model)` —— 打印网络结构清单，`nn.Module` 会自动列出所有已注册的子层及参数形状（见后文“运行结果与解读”的前 5 行）。写网络时养成打印结构的习惯，能快速发现维度写错的问题。

### 第 3 部分：损失函数与优化器

```python
criterion = nn.CrossEntropyLoss()  # 交叉熵损失：分类任务的标准损失函数
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)  # SGD 优化器，学习率 0.1
# model.parameters() 把模型所有可学习参数交给优化器管理
```

- `criterion = nn.CrossEntropyLoss()` —— 创建交叉熵损失函数，变量名 `criterion`（标准、准则）是社区惯用叫法。它内部包含 softmax，接收两个东西：**模型输出的原始得分**（形状 `(32, 2)`）和**真实标签的类别编号**（形状 `(32,)`，整型），返回一个标量损失值。分类任务默认选它；
- `optimizer = torch.optim.SGD(model.parameters(), lr=0.1)` —— 创建 SGD（随机梯度下降）优化器。第一个参数 `model.parameters()` 把模型里**所有**可学习参数（3 个权重矩阵 + 3 个偏置向量，共 202 个）交给优化器统一打理；`lr=0.1` 是学习率，即每次更新的步长系数。之后只要调用 `optimizer.step()`，它就会对每个参数执行 `参数 ← 参数 - 0.1 × 梯度`，不需要你手动逐个更新。

### 第 4 部分：训练循环（五步曲）

```python
for epoch in range(50):  # 训练 50 轮
    total_loss = 0.0  # 累计本轮总损失
```

- `for epoch in range(50):` —— 外层循环跑 50 个 epoch（轮次），即把全部 500 条数据完整学习 50 遍。`epoch` 从 0 数到 49；
- `total_loss = 0.0` —— 每轮开始时把损失累加器清零。注意它放在外层循环**里面**，这样每轮统计的都是“本轮”的损失，不会和上一轮混在一起。

```python
    for batch_X, batch_y in loader:  # 逐批次取数据
        pred = model(batch_X)  # 第 1 步：前向传播，得到预测得分 (32, 2)
```

- `for batch_X, batch_y in loader:` —— 内层循环：从 `DataLoader` 里逐批取数据。每次迭代 `batch_X` 是形状 `(32, 2)` 的特征（最后一批是 `(20, 2)`），`batch_y` 是形状 `(32,)` 的标签。一轮内层循环跑完 16 批，正好过完 500 条数据；
- `pred = model(batch_X)` —— **第 1 步：前向传播**。把这一批特征喂给模型，自动触发 `forward` 方法，输出 `pred` 形状 `(32, 2)`——每一行是一个样本在“类别 0、类别 1”上的两个得分。注意写法是 `model(batch_X)` 而不是 `model.forward(batch_X)`：直接调用模型对象才能正确触发框架的钩子机制。

```python
        loss = criterion(pred, batch_y)  # 第 2 步：计算损失
        optimizer.zero_grad()  # 第 3 步：清空上一轮的梯度
        loss.backward()  # 第 4 步：反向传播计算梯度
        optimizer.step()  # 第 5 步：优化器根据梯度更新参数
```

- `loss = criterion(pred, batch_y)` —— **第 2 步：计算损失**。把预测得分 `(32, 2)` 和真实标签 `(32,)` 交给交叉熵，得到这批数据的平均损失，是一个标量张量；
- `optimizer.zero_grad()` —— **第 3 步：清空梯度**。PyTorch 默认会**累加**梯度（每次 `backward` 把新梯度加到旧梯度上），如果不清零，这一批的梯度就会混入上一批的，参数更新方向就错了。所以每一批都要先清零——忘记写这行是新手最常见的 bug 之一；
- `loss.backward()` —— **第 4 步：反向传播**。从损失出发，沿计算图自动求出损失对每个参数的梯度（即“每个参数该往哪个方向调、调多少”），梯度存进各参数的 `.grad` 属性里。这一行是 PyTorch 自动微分（autograd，第 2 章）的用武之地；
- `optimizer.step()` —— **第 5 步：更新参数**。优化器读取每个参数的 `.grad`，执行 `参数 ← 参数 - 0.1 × 梯度`。至此，一批数据的完整训练结束，模型参数朝损失减小的方向挪了一小步。
- 五行的顺序是约定俗成的：**先清零再 backward，先 backward 再 step**，顺序错了训练就失效，请按口诀“前向 → 损失 → 清零 → 反传 → 更新”记牢。

```python
        total_loss += loss.item()  # .item() 取出标量值并累加
```

- `loss.item()` 把标量损失从张量中取成普通的 Python 浮点数，再累加进 `total_loss`，用于稍后计算本轮平均损失。**必须用 `.item()`**：如果直接写 `total_loss += loss`，累加的是带计算图的张量，既浪费内存又可能把梯度图越串越长。这是新手第二个常见坑。

### 定期评估与打印

```python
    if (epoch + 1) % 10 == 0:  # 每 10 轮评估一次
        with torch.no_grad():  # 评估时关闭梯度计算，节省内存
            acc = (model(X).argmax(dim=1) == y).float().mean()  # 预测类别与真实标签比较
```

- `if (epoch + 1) % 10 == 0:` —— 每 10 轮执行一次评估。`epoch` 从 0 开始，所以加 1 后正好是 10、20、30、40、50 时条件成立；
- `with torch.no_grad():` —— 进入“不计算梯度”的上下文：评估只是为了看效果，不需要更新参数，关掉梯度可以省内存、提速度，也能防止误改参数；
- `acc = (model(X).argmax(dim=1) == y).float().mean()` —— 一行连写四个操作，从左到右读：
  - `model(X)`：把全部 500 条数据一次性过模型，得到得分 `(500, 2)`；
  - `.argmax(dim=1)`：沿第 1 维（每行的 2 个得分）取最大值的**下标**，即预测的类别编号，结果形状 `(500,)`；
  - `== y`：逐元素与真实标签比较，得到布尔张量 `(500,)`，True 表示这条预测对了；
  - `.float().mean()`：True→1.0、False→0.0 后求平均，即准确率（预测正确的比例）。

```python
        print(f"第 {epoch+1:2d} 轮 | 平均损失={total_loss/len(loader):.4f} | 准确率={acc:.2%}")
```

- 这行用 f-string 打印本轮训练情况，三个格式化占位符：
  - `{epoch+1:2d}`：打印轮次（1~50），`:2d` 表示整数至少占 2 个字符宽，个位数前面补空格，输出对齐更美观；
  - `{total_loss/len(loader):.4f}`：`len(loader)` 是批次数 16，`total_loss` 除以它得到**本批次的平均损失**，`.4f` 保留 4 位小数；
  - `{acc:.2%}`：把准确率按百分比格式输出、保留 2 位小数，例如 `0.978` 显示为 `97.80%`。

## 运行结果与解读

实际运行 `python examples/04_first_neural_network.py`，输出如下：

```text
MLP(
  (layer1): Linear(in_features=2, out_features=16, bias=True)
  (relu): ReLU()
  (layer2): Linear(in_features=16, out_features=8, bias=True)
  (layer3): Linear(in_features=8, out_features=2, bias=True)
)
第 10 轮 | 平均损失=0.1632 | 准确率=97.00%
第 20 轮 | 平均损失=0.0835 | 准确率=97.80%
第 30 轮 | 平均损失=0.0650 | 准确率=99.00%
第 40 轮 | 平均损失=0.0523 | 准确率=98.80%
第 50 轮 | 平均损失=0.0504 | 准确率=98.80%
```

逐项解读：

- **前 5 行是 `print(model)` 打印的网络结构**：每个括号对应 `__init__` 里注册的一个子层，`in_features=2, out_features=16` 表示 layer1 输入 2 维、输出 16 维，`bias=True` 表示带偏置。逐层检查：2→16→8→2，维度衔接正确，说明网络搭对了。如果你打印出来的维度和这里不一致，先回头检查 `nn.Linear` 的参数；
- **平均损失单调下降**：从第 10 轮的 0.1632 一路降到第 50 轮的 0.0504，说明五步曲训练正常、参数确实在朝减小损失的方向更新。如果损失不降反升或原地不动，先检查是不是忘了 `zero_grad()`，或者学习率不合适；
- **准确率稳步爬升到 98% 以上**：第 10 轮已达 97.00%，第 30 轮升到 99.00%，最终稳定在 98.80%。这说明这个只有 202 个参数的小网络成功学会了圆形的分类边界——**非线性问题被 ReLU 激活的多层网络解决了**；
- **第 40、50 轮准确率都是 98.80%，略有回落属正常**：因为 `shuffle=True` 且模型仍在更新，个别处于边界附近的样本会在“对/错”之间波动，0.2% 的抖动（恰好 1 个样本）不代表训练变差，看整体趋势即可；
- **损失降了但准确率不变也是常见现象**：准确率在 98.80% 时损失仍从 0.0523 降到 0.0504，说明模型对预测正确的样本越来越“自信”（正确类别的概率更接近 1），这正是交叉熵损失的特性。

## 小结

- 自定义网络的固定套路：继承 `nn.Module`，在 `__init__` 里用 `self.` 注册各层，在 `forward` 里写数据流动路径；
- ReLU 提供非线性，没有它多层网络退化为单层线性模型，学不会圆形这类非线性边界；
- 输出层直接输出各类别得分（logits），不要加 softmax——`nn.CrossEntropyLoss` 已内置；
- 训练五步曲：前向传播 → 算损失 → `zero_grad()` → `backward()` → `step()`，顺序不能乱，梯度每批必须清零；
- 判断训练好坏看两条曲线：损失应稳步下降，准确率应稳步上升并趋于稳定。

## 动手练习

1. **去掉激活函数**：把 `forward` 改成 `x = self.layer1(x)`、`x = self.layer2(x)`、`return self.layer3(x)`（即不接 ReLU），再运行，观察准确率是否明显上不去——体会非线性激活的作用；
2. **调学习率**：把 `lr=0.1` 分别改成 `lr=0.01` 和 `lr=1.0` 各运行一次，对比损失下降的速度和稳定性，回答：学习率太小和太大各自会发生什么现象？
3. **改网络容量**：把隐藏层从 `Linear(2, 16)`、`Linear(16, 8)` 改成 `Linear(2, 4)`、`Linear(4, 4)`（注意 `layer3` 的输入维度也要跟着改成 4），运行后观察最终准确率的变化，思考“网络太窄”会带来什么问题。
